# DAIMOS SELF-HOSTING USERLAND TOOL SET

THIS DOCUMENT LISTS THE USERLAND TOOLS NEEDED FOR AN EARLY SELF-HOSTING DAIMOS SYSTEM.

SELF-HOSTING MEANS THAT DAIMOS CAN BOOT, MOUNT ITS OWN STORAGE, EDIT SOURCE, BUILD THE KERNEL AND USERLAND, INSTALL THE RESULT, DIAGNOSE FAILURES, AND RECOVER WITHOUT DEPENDING ON ANOTHER RUNNING OPERATING SYSTEM.

EXTERNAL HOST-SIDE TOOLS MAY STILL BE USED FOR IMPORTING AND EXPORTING FILES. THEY ARE NOT PART OF THE NATIVE SELF-HOSTING REQUIREMENT.

## 1. COMMAND ENVIRONMENT

### REQUIRED TOOLS

- 'SH' OR 'KSH'
- 'ENV'
- 'TRUE'
- 'FALSE'
- 'TEST'
- 'ECHO'
- 'PRINTF'
- 'PWD'
- 'SLEEP'
- 'KILL'

THE EARLY SHELL DOES NOT NEED TO BE FULLY POSIX-COMPATIBLE, BUT IT MUST BE STABLE ENOUGH TO RUN DAIMOS BUILD AND INSTALL SCRIPTS. A SMALL NATIVE KSH-LIKE SHELL IS PREFERRED.

## 2. BASIC FILE TOOLS

### REQUIRED TOOLS

- 'LS'
- 'CP'
- 'MV'
- 'RM'
- 'MKDIR'
- 'RMDIR'
- 'CAT'
- 'MORE'
- 'TOUCH'
- 'FIND'
- 'DF'
- 'DU'

THESE ARE NORMAL COMMAND-LINE FILE TOOLS. THEIR BEHAVIOR SHOULD FOLLOW FAMILIAR UNIX CONVENTIONS WHERE THAT DOES NOT CONFLICT WITH DAIMOS FILESYSTEM SEMANTICS.

## 3. TEXT EDITING

### REQUIRED TOOLS

- 'ED'
- 'ELVIS'

'ED' IS THE EMERGENCY EDITOR. IT SHOULD BE TINY, DEPENDABLE, AND USABLE ON A MINIMAL CONSOLE.

'ELVIS' IS THE PRACTICAL SOURCE EDITOR FOR NORMAL NATIVE DEVELOPMENT.

## 4. BUILD TOOLS

### REQUIRED TOOLS

- 'MAKE'
- 'AWK'
- 'INSTALL'
- 'CMP'
- 'DIFF'
- 'SED'
- 'GREP'
- 'SORT'
- 'UNIQ'
- 'XARGS'

'MAKE' IS REQUIRED FOR KERNEL, LIBRARY, AND USERLAND BUILDS.

'SED', 'GREP', 'SORT', 'UNIQ', AND 'XARGS' ARE NEEDED BECAUSE EVEN SMALL BUILD SYSTEMS TEND TO DEPEND ON THEM. THE EARLY VERSIONS CAN BE LIMITED, BUT THEIR SUPPORTED SUBSET MUST BE DOCUMENTED AND STABLE.

## 5. NATIVE TOOLCHAIN

### REQUIRED TOOLS AND COMPONENTS

- 'KCC'
- 'CPP'
- 'AS'
- 'LD'
- 'DARC'
- 'NM'
- 'SIZE'
- 'STRIP'
- 'DOBJDUMP'
- 'LIBC'
- 'CRT0'
- 'LIBSYS'

### 'KCC'

'KCC' IS THE NATIVE DAIMOS C COMPILER.

IT IS THE PREFERRED SELF-HOSTING COMPILER BECAUSE IT CAN REMAIN SMALLER AND MORE SUITABLE FOR PDP-6/KA10-CLASS SYSTEMS THAN GCC.

### 'CPP'

THE C PREPROCESSOR MAY BE STANDALONE OR INTEGRATED INTO 'KCC'.

FOR SELF-HOSTING, IT MUST SUPPORT THE SUBSET NEEDED BY THE DAIMOS KERNEL, LIBC, USERLAND, AND BUILD SYSTEM.

### 'DAS'

THE NATIVE ASSEMBLER MUST SUPPORT THE DAIMOS ASSEMBLY SYNTAX USED BY THE KERNEL, BOOT CODE, RUNTIME STARTUP FILES, AND LOW-LEVEL LIBRARIES.

### 'LD'

THE NATIVE LINKER PRODUCES DAIMOS EXECUTABLE AND KERNEL IMAGES.

IT SHOULD UNDERSTAND THE DAIMOS OBJECT MODEL DIRECTLY INSTEAD OF IMITATING UNIX LINKER BEHAVIOR WHERE THAT WOULD CREATE UNNECESSARY COMPATIBILITY BAGGAGE.

### 'DARC'

'DARC' IS THE NATIVE DAIMOS ARCHIVE AND OBJECT-LIBRARY TOOL.

IT REPLACES THE NEED FOR UNIX-STYLE ARCHIVE TOOLS IN THE NATIVE SYSTEM. IT SHOULD SUPPORT BOTH GENERAL DAIMOS ARCHIVE USE AND STATIC LIBRARY USE FOR THE LINKER.

A 'DARC' ARCHIVE SHOULD PRESERVE DAIMOS-NATIVE METADATA WITHOUT LOSSY TRANSLATION:

- SIXBIT NAMES WHERE APPLICABLE
- DAIMOS FILE CLASS/TYPE
- WORD-EXACT FILE LENGTH
- MEMBER CHECKSUMS
- LIBRARY MEMBER INDEX
- TOOLCHAIN METADATA

EXTERNAL ARCHIVE FORMATS ARE HANDLED BY HOST-SIDE IMPORT/EXPORT TOOLS, NOT BY THE NATIVE SELF-HOSTING SET.

### 'DOBJDUMP'

'DOBJDUMP' INSPECTS DAIMOS OBJECT FILES, EXECUTABLES, KERNEL IMAGES, AND ARCHIVES.

IT SHOULD BE DAIMOS-SPECIFIC RATHER THAN A CLONE OF A UNIX OBJECT DUMPER.

## 6. RUNTIME LIBRARIES

### REQUIRED COMPONENTS

- 'LIBC'
- 'CRT0'
- 'LIBSYS'

THE C RUNTIME MUST PROVIDE ENOUGH SUPPORT FOR THE COMPILER, BUILD TOOLS, SHELL, EDITOR, AND SYSTEM TOOLS.

### IMPORTANT INTERFACES

- 'OPEN'
- 'READ'
- 'WRITE'
- 'CLOSE'
- 'LSEEK'
- 'FORK'
- 'EXEC'
- 'WAIT'
- 'EXIT'
- 'MALLOC'
- 'FREE'
- 'STDIO'
- STRING ROUTINES
- DIRECTORY READING
- TIME AND FILE TIMESTAMPS
- TERMINAL CONTROL

FILE TIMESTAMPS ARE REQUIRED BECAUSE 'MAKE' DEPENDS ON THEM.

## 7. SYSTEM ADMINISTRATION

### REQUIRED TOOLS

- 'INIT'
- 'MOUNT'
- 'UMOUNT'
- 'FSCK'
- 'MKFS'
- 'SYNC'
- 'HALT'
- 'REBOOT'
- 'PS'
- 'STTY'
- 'TTY'
- 'DMESG'

SINGLE-USER SELF-HOSTING CAN START WITHOUT FULL LOGIN INFRASTRUCTURE.

MULTI-USER OPERATION LATER ADDS:

- 'GETTY'
- 'LOGIN'
- 'PASSWD'
- 'WHO'
- 'ID'
- 'CHMOD'
- 'CHOWN'
- 'LN'

THESE TOOLS DEPEND ON THE FINAL DAIMOS USER, PERMISSION, AND NAMESPACE MODEL.

## 8. DAIMOS STORAGE AND BOOT TOOLS

### REQUIRED TOOLS

- 'INSTALLBOOT'
- 'DSKLABEL'
- 'BADSCAN'
- 'FSCK.D6FS'
- 'MKFS.D6FS'
- 'DD'
- 'OD'
- 'CKSUM'

### 'INSTALLBOOT'

'INSTALLBOOT' WRITES OR UPDATES THE DAIMOS BOOT LAYOUT.

IT MUST UPDATE THE BOOT/MEDIA DESCRIPTOR USED BY STAGE1 AND KINIT. IT IS RESPONSIBLE FOR INSTALLING THE KERNEL IMAGE, BOOT MODULE AREA, BOOT CONFIGURATION, DESCRIPTOR GENERATION DATA, AND CHECKSUMS.

IT MUST NOT REQUIRE STAGE1 TO PARSE AN ORDINARY FILESYSTEM.

### 'DSKLABEL'

'DSKLABEL' INSPECTS AND WRITES THE DAIMOS DISK LAYOUT.

IT SHOULD DESCRIBE THE RESERVED BOOT/SYSTEM REGIONS, FILESYSTEM REGION, BAD-SECTOR METADATA, STRIPE MEMBERSHIP, DESCRIPTOR GENERATION, AND CHECKSUM STATE.

### 'BADSCAN'

'BADSCAN' SCANS DISK MEDIA AND RECORDS BAD-SECTOR INFORMATION IN THE DAIMOS MEDIA DESCRIPTOR OR ITS CONTINUATION RECORDS.

THE FILESYSTEM SHOULD NORMALLY SEE ONLY USABLE LOGICAL BLOCKS; BAD-SECTOR HANDLING BELONGS TO THE MEDIA/LAYOUT LAYER.

### 'FSCK.D6FS'

'FSCK.D6FS' CHECKS AND REPAIRS THE NATIVE DAIMOS DISK FILESYSTEM.

IT SHOULD UNDERSTAND DAIMOS WORD-ORIENTED STORAGE, FILE METADATA, GENERATION FIELDS, AND CONSISTENCY RULES.

### 'MKFS.D6FS'

'MKFS.D6FS' CREATES A NATIVE DAIMOS DISK FILESYSTEM.

IT SHOULD COOPERATE WITH 'DSKLABEL' AND AVOID REGIONS RESERVED FOR BOOT, KERNEL, MODULES, SWAP, LOGS, AND BAD-SECTOR METADATA.

## 9. DIAGNOSTICS AND RECOVERY

### REQUIRED TOOLS

- 'DMESG'
- 'DEVSTAT'
- 'MEMSTAT'
- 'OD'
- 'NM'
- 'SIZE'
- 'DOBJDUMP'

### 'DEVSTAT'

'DEVSTAT' SHOWS DEVICE AND DRIVER STATE.

FOR EARLY DAIMOS THIS IS ESPECIALLY USEFUL FOR DISK, CONSOLE, TAPE, CARD READER/PUNCH, AND BOOT-DEVICE DIAGNOSTICS.

### 'MEMSTAT'

'MEMSTAT' SHOWS MEMORY USAGE AND MEMORY MAP INFORMATION.

ON SMALL PDP-6/KA10-CLASS SYSTEMS, THIS IS IMPORTANT FOR KEEPING THE KERNEL AND USERLAND WITHIN REALISTIC MEMORY LIMITS.

## 10. MINIMAL FIRST MILESTONE

A STRICT FIRST SELF-HOSTING MILESTONE SHOULD INCLUDE:

- 'INIT'
- 'SH' OR 'KSH'
- 'LS', 'CP', 'MV', 'RM', 'MKDIR', 'RMDIR', 'CAT', 'MORE'
- 'MOUNT', 'UMOUNT', 'FSCK', 'MKFS', 'SYNC', 'HALT', 'REBOOT'
- 'ED' OR 'ELVIS'
- 'MAKE'
- 'KCC'
- 'CPP'
- 'AS'
- 'LD'
- 'DARC'
- 'LIBC'
- 'CRT0'
- 'LIBSYS'
- 'INSTALL'
- 'SED'
- 'GREP'
- 'CMP'
- 'DIFF'
- 'TOUCH'
- 'SORT'
- 'OD'
- 'PS'
- 'KILL'
- 'STTY'
- 'INSTALLBOOT'
- 'DSKLABEL'
- 'BADSCAN'
- 'FSCK.D6FS'
- 'MKFS.D6FS'
- 'CKSUM'

THIS IS ENOUGH FOR DAIMOS TO EDIT, BUILD, INSTALL, BOOT, INSPECT, AND REPAIR ITSELF FROM ITS OWN CONSOLE.
