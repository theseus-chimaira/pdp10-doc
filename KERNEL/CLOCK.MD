# DAIMOS APR AND WALL-CALENDAR CLOCKS

DATE: 2026-10-28
STATUS: NATIVE PDP-6 IMPLEMENTATION VERIFIED THROUGH V618

## 1. TWO INDEPENDENT CLOCK FUNCTIONS

THE PDP-6 APR LINE CLOCK PROVIDES MONOTONIC TICKS FOR SCHEDULING, SLEEP,
STORAGE TIMEOUTS, DEVICE TIMING, AND PROCESS ACCOUNTING. IT IS NOT A
CIVIL-TIME CLOCK. THE INSTALLER SELECTS `WALL_CLOCK_HZ=50` OR `60` WHEN
BUILDING THE KERNEL; THE DEFAULT IS 60. THE SOFTWARE WALL CALENDAR USES
THIS HARDWARE TICK RATE, BUT HISTORICAL SCHEDULER/DEVICE TIMEOUT ASSUMPTIONS
ABOUT 60 HZ STILL REQUIRE A SYSTEM-WIDE 50-HZ AUDIT.

DAIMOS SUPPORTS TWO INTERCHANGEABLE UTC WALL-CALENDAR SOURCES:

* PCLK: STANFORD PHIL PETIT CALENDAR HARDWARE AT I/O DEVICE 0730.
* SCLK: AN APR-DRIVEN SOFTWARE UTC CALENDAR, INITIALIZED BY THE OPERATOR.

PCLK IS OPTIONAL. THE APR SCHEDULER MRES IS SHARED BY BOTH CONFIGURATIONS.
NEITHER SOURCE IMPLEMENTS TIMEZONES OR DAYLIGHT SAVING TIME. THOSE ARE
USERSPACE POLICY; ALL KERNEL TIMESTAMPS ARE UTC.

## 2. KINIT PROVIDER SELECTION AND MRES

KINIT `clk_minit` INSTALLS THE SHARED APR CLOCK SERVICE AND PROBES PCLK
ONCE USING A COHERENT HARDWARE READ. ITS TRANSIENT CODE VALIDATES THE
RETURNED TIME36, INCLUDING BCD DIGITS, RANGE, MONTH LENGTHS, AND LEAP YEARS.
A VALID DATE SELECTS PCLK; ABSENT, UNSET, OR INVALID HARDWARE SELECTS SCLK.

`pclkclock_minit` INSTALLS THE PCLK MRES ONLY FOR THE HARDWARE CASE.
`softclock_minit` INSTALLS THE SOFTWARE-CALENDAR MRES ONLY FOR THE FALLBACK
CASE, PROVIDED APR IS USABLE. KINIT PATCHES THE SINGLE PERMANENT KCORE
`wall_time36` JRST TO THE CHOSEN READ ROUTINE; THE SCLK CASE ALSO PATCHES
THE PRIVILEGED SETTIME GATEWAY. THE UNSELECTED PROVIDER IMAGE IS RECLAIMED
WITH THE TRANSIENT KINIT SOURCE AND DOES NOT OCCUPY PERMANENT MEMORY.

PCLK AND SCLK NEVER BOTH INSTALL. PROVIDER SELECTION DOES NOT CHANGE AFTER
BOOT; NO AUTOMATIC FAILOVER OR SEPARATE BROKEN-HARDWARE CLASSIFICATION EXISTS.
A PLAUSIBLE BUT INCORRECT PCLK DATE CANNOT BE DETECTED WITHOUT EXTERNAL TIME.

## 3. TIME36 ABI

GETTIME RETURNS ONE CHRONOLOGICALLY SORTABLE, PACKED 36-BIT UTC VALUE:

    BIT 35        ZERO
    BIT 34        0 = 20XX, 1 = 21XX
    BITS 33..26   TWO BCD YEAR DIGITS
    BITS 25..22   MONTH, 1..12
    BITS 21..17   DAY, 1..31
    BITS 16..12   HOUR, 0..23
    BITS 11..6    MINUTE, 0..59
    BITS 5..0     SECOND, 0..59

ZERO MEANS UNKNOWN OR UNINITIALIZED. SUPPORTED DATES RUN FROM
2026-01-01 THROUGH 2125-12-31 UTC. HARDWARE YEAR DIGITS 26..99 MEAN
2026..2099 AND 00..25 MEAN 2100..2125. TIME36 IS NOT UNIX OR MJD
EPOCH SECONDS; NO 1858-EPOCH CONVERSION IS RESIDENT IN THE KERNEL.

ROOT-ONLY SETTIME INITIALIZES/ADJUSTS SCLK AND REJECTS INVALID DATES.
THE HARDWARE PCLK PROVIDER IS READ-ONLY: SETTIME ALWAYS FAILS THERE.
UNSET SCLK IS INITIALIZED THROUGH USERSPACE DATE, INCLUDING THE ROOT LOGIN
PROMPT WHEN THE CALENDAR HAS NEVER BEEN SET.

## 4. HARDWARE READER AND SOFTWARE CALENDAR

THE TRANSIENT KINIT PROBE AND OPTIONAL PCLK MRES SHARE THE COHERENT READER.
DATAI 0730 IS SAMPLED BEFORE AND AFTER CONI 0730; THE READER RETRIES
WHEN THE TWO DATAI WORDS DIFFER AT A MINUTE BOUNDARY. HISTORICAL DEVICE
OFFSETS (DATAI 05004 AND CONI 02020136700) ARE REMOVED BEFORE PRODUCING
TIME36. PCLK NEEDS NO CALENDAR ADVANCEMENT LOOP OR APR INTERRUPT.

SCLK STORES A TIME36 VALUE AND A TICK-BASE WORD. THE APR HANDLER ONLY
INCREMENTS A COMPACT MONOTONIC TICK WORD; IT DOES NOT PERFORM CALENDAR
ARITHMETIC IN INTERRUPT CONTEXT. SCLK ADVANCES UTC LAZILY WHEN READ,
USING THE BUILT-IN 50/60-HZ RATE. PI-MASKED SNAPSHOTS AND GUARDED
PUBLICATION PROTECT AGAINST CONCURRENT SETTIME AND GETTIME UPDATES.
THE SOFTWARE CALENDAR HANDLES GREGORIAN MONTH LENGTHS AND LEAP YEARS.
MONTH LENGTHS ARE ENCODED BY A COMPACT BIT MASK INSTEAD OF A BYTE ARRAY.

## 5. FILESYSTEM AND USERSPACE TIMESTAMPS

THE SHARED `wall_time36` ENTRY SUPPLIES GETTIME AND FILESYSTEM TIMESTAMPS.
D6FS STORES TIME36 IN ITS PERSISTENT FCB MTIME WORD; MEMFS USES A TIME36
WORD PER NODE AND PRESERVES IT IN SNAPSHOTS. TOUCH AND UTIME FOLLOW THE
EXISTING FILE/OWNER PERMISSION RULES. DTFS, TSFS AND MONITORFS MAY RETURN
MTIME ZERO WHEN THE FORMAT DOES NOT SUPPORT A MEANINGFUL MODIFICATION TIME.

DATE DISPLAYS AND SETS UTC. LIBC TIME/STAT AND MAKE CONSUME THE TIME36 ABI.
LOCAL TIME AND DAYLIGHT SAVING CONVERSION REMAIN OUTSIDE KCORE.

## 6. VERIFIED BUILD AND NATIVE ACCEPTANCE

NATIVE DAIMOS-TESTKIT V618 BOOTS THE PDP-6 WITH PCLK ENABLED AND DISABLED,
AT BOTH `WALL_CLOCK_HZ=50` AND `60`. IT ASSERTS THE EXCLUSIVE PCLK/SCLK
BOOT DIAGNOSTIC AND EXERCISES GETTIME, SETTIME PERMISSIONS, VALID/INVALID
CALENDAR DATES, AND LEAP-DAY MIDNIGHT ROLLOVER. ALL FOUR CONFIGURATIONS PASS.
EARLIER V609/V610 NATIVE TESTS ALSO COVER D6FS AND MEMFS MTIME UPDATES.

LOWMEM GCC LINKED COUNTS (V618):

    KCORE                     8537 WORDS
    SHARED APR MRES             42 WORDS
    OPTIONAL PCLK MRES          26 WORDS
    OPTIONAL SCLK MRES         329 WORDS
    CONSERVATIVE ALL-MRES    15972 WORDS

THE CONSERVATIVE REPORT COUNTS BOTH CLOCK PROVIDERS. ONLY ONE INSTALLS.
EXCLUDING THE UNSELECTED MRES GIVES 15643 WORDS FOR PCLK OR 15946
FOR SOFTWARE UTC, BEFORE OTHER OPTIONAL MODULE-OMISSION ADJUSTMENTS.

## 7. REMAINING HARDWARE ACCEPTANCE

PHYSICAL PDP-6 50-HZ TIMING ACCURACY AND NON-WALL-CLOCK SCHEDULER/DEVICE
RATE ASSUMPTIONS REMAIN SEPARATE ACCEPTANCE ITEMS. SIMH GENERATES ITS
APR TICKS AT ITS BUILT-IN RATE; THE 50-HZ REGRESSIONS VALIDATE THE
KERNEL'S CONFIGURED TICK CONVERSION, NOT AN EXTERNAL 50-HZ OSCILLATOR.
A PCLK WHICH LATER FAILS DOES NOT TRIGGER RUNTIME RECONFIGURATION.

## 8. V621 APR COUNTER CONSOLIDATION

THE MONOTONIC APR CLOCK AND SCLK SHARE THE SAME 36-BIT TICK COUNTER IN
FIXED KCORE (`clk_tick_count` AND `wall_clock_ticks` ALIAS ONE WORD).
EACH REAL APR INTERRUPT INCREMENTS IT EXACTLY ONCE, INCLUDING PCLK BOOTS.
THERE IS NO DUPLICATE COUNTER, CONDITIONAL PATCH, OR SECOND CLOCK-TICK
INCREMENT. APR MRES RESIDENCY FELL BY TWO WORDS (46 TO 44), WHILE
CONSERVATIVE KCORE+MRES FELL FROM 15976 TO 15974 WORDS. NATIVE PCLK
ENABLED/DISABLED BOOTS PASS AT 50 AND 60 HZ. A BULK-CALENDAR EXPERIMENT
(+42 WORDS) AND A PACKED-ROLLOVER EXPERIMENT (+22 WORDS) WERE BOTH
REJECTED UNDER RAM-FIRST OPTIMIZATION PRIORITIES.

## 9. V622 DEAD APR EXPORT REMOVAL

THE UNUSED `clk_ticks()` FUNCTION AND ITS MRES EXPORT WERE REMOVED AFTER
SOURCE AUDIT CONFIRMED NO CALLERS. THE EXISTING KCORE TICK COUNTER AND
DISPLAY-CLOCK PATCHING REMAIN UNCHANGED. APR MRES RESIDENCY FELL FROM
44 TO 42 WORDS; CONSERVATIVE KCORE+MRES FELL FROM 15974 TO 15972 WORDS.
NATIVE PCLK ENABLED/DISABLED BOOTS PASS AT 50 AND 60 HZ. LOWMEM GCC LINK
PASSES; THE 50-HZ NATIVE TEST USES A DUMMY SDL VIDEO BACKEND.
