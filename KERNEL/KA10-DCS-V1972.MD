The installed pdp10-ka includes the same pdp6_dcs.c source
as pdp6, but the KA10 branch deliberately preserves the
historical WAITS register convention: line bias2, DCSB
CONO selects the biased send line and DCSB DATAO sends
to it. DAIMOS logical TTY mapping remains unchanged.
The PDP-6 variant uses zero-based line numbers and DCSA
DATAO. The KA10 adaptation is limited to dcs_io.s and the
machine-selected assembly prefix; no emulator modification.
DCS shares PI2 with RM10. Claim a receiver only when its
PIA is2 and scanner stopped; an unarmed idle scanner must
not fabricate input during another device's interrupt.

Enable the existing DCS package and MINIT on KA10, leave
GE excluded. Default native boot.ini sets dcs enabled,
lines=8 and attaches dcs0 to the configured SIMH_DCS0_PORT
(default1101). Native INITTAB selects both CTY0 and logical
TTY1 (DCS0). The simulator supports16 lines; default8
matches existing PDP-6 configuration. No claim that all
sixteen physical lines or native hardware are qualified.
