# Requester-only BRK OOM: frozen first release-candidate profile v1160

Date: 2026-11-05. Scope gate: S07/S08 of the v1123 OOM checklist.
This is a *profile freeze*, not approval to change the production
`PROC_OOM_BRK_ENABLED_V1000` switch. E13 and all F gates remain open.

## Included target and hardware/media profile

| Item | Exact first candidate |
| --- | --- |
| CPU/simulator | PDP-6, Open SIMH `pdp6` V4.1-0, build `edd19b17` on Android aarch64 |
| Memory | `BOOT_PROFILE=full`, `BOOT_CORE_WORDS=01000000`, `SIMH_CPU_KWORDS=256` |
| Compiler | KCC `COMPILER=kcc`; `VM_BACKEND=pdp6` |
| Clock | `WALL_CLOCK_HZ=60`, PCLK enabled, `SIMH_PCLK_MODE=REALTIME` |
| First-stage boot | `BOOT=dsk`, DSK270, `ROOT=disk`, `ROOTSET=1` (console SW=1) |
| Root | Real generated four-member D6FS/DSK, BLOCKSET enabled |
| Auxiliary media | DRM236/drum AUXSTORE built and attached; DSK and drum backing media generated by the normal image rules |
| Backing policy | `/CONFIG/SYSTEM` requests `SWAP=AUTO`, `LOGSTORE=AUTO`; D6FS swap tail defaults to `0400` blocks, drum backstore to `010000` blocks |
| Filesystems and kernel services | D6FS, BLOCKSET, LOGSTORE, MEMFS and TTY boot-loaded in the observed full image; MonitorFS boot MRES required (`MONITORFS_MRES_ENABLED=1`) |
| Console during E13 guest | CTY, `SIMH_DPY_MODE=HEADLESS`; WCNSLS and OCNSLS disabled in the test copy's simulator configuration |
| Process ABI | Normal writable `RUN`/`EXEC` VM startup; requester-only fatal physical `BRK` when test-enabled, ordinary `-1` otherwise |

These settings are the **first bounded OOM release-candidate scope**.
They do not disable other DAIMOS features for ordinary installations.
The full simulator hardware template still makes several additional
devices available and may load their MRES drivers; packaging an MRES
is not proof that it remains permanently resident. No permanent MRES
occupancy or 16K mapping result is asserted here (F05/F06 remain).

This E13 guest uses the normal disk/media builder and filesystem
provider code but replaces `/SYSTEM/INIT` with a disposable test
program. Consequently, the available backing media and the configured
`SWAP=AUTO` policy are identified, **not** claimed as a verified
normal-userland swap activation. Runtime swap and peak-RAM signoff
remain F04/F07 work.

## Deliberately excluded from this first OOM acceptance profile

- Deferred strict 32K `BOOT_PROFILE=lowmem` with GCC and DSH budget.
- `ROOT=tape` TSFS/DTFS, `ROOT=drum`, and automatic/alternate root
  selection, even if some packages remain available in the full image.
- Stage 1 from DTC, MTC, PTR or DRM; only DSK Stage 1 is certified
  by the v1160 E13 evidence.
- MEMFS raw-XIP `RUN`/`EXEC` process admission. Normal process loaders
  remain writable, verified by the v1123 source/mutant guard.
- GUI Type-340/DPY login, live multi-terminal user sessions and
  optional interactive hardware beyond the headless CTY probe.
- Any alternate emulator, simulator version, CPU implementation,
  boot media or provider combination not explicitly reproduced in
  the archived E13 evidence.

This exclusion list limits what can be **accepted for enabling BRK
OOM**, not which older filesystem/device formats DAIMOS supports.
The OOM switch stays OFF everywhere until complete final acceptance.

## v1160 first-platform evidence and residual gates

The testkit `test-daimos-oom-release-media-v1160` rebuilt two
independent 256K guests with the exact DSK/D6FS options above. Both
normal-disabled and isolated enabled OOM cases PASS. Each performs
actual BRK physical exhaustion while a foreign filesystem gateway
owner holds a real lease, checks original-owner retry/unlock, INIT,
independent runnable user, WAIT and process/MM accounting.

The evidence archive is generated under `$TMPDIR` as
`daimos-e13-release-media-v1160.<unique>.tar.gz`, alongside its SHA256.
This run used the local Android/aarch64 Open SIMH `pdp6` simulator.
It includes complete simulator/counter transcripts, build logs,
actual boot.ini, maps, profile and host-tool/D6FS media checksums;
generated multi-member media are *hashed*, not bundled. The captured
boot confirms DSK270, DRM236, BLOCKSET, LOGSTORE, MEMFS and D6FS.

**S07 and S08 freeze this exact candidate only.** E13 is still OPEN:
the required independent simulator targets and alternate release
media coverage have not all been reproduced or agreed for signoff.
A04 and F02-F11 must be rerun on an exact frozen candidate before
any production default enable; F12/F13 are post-signoff actions.
