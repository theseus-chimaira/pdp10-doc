# DSH AND CORE COMMANDS V1
STATUS: CONSOLIDATED ACTIVE USERLAND SHELL DOCUMENTATION. SOURCE OF TRUTH: '../DAIMOS/DOCS/DSH_COREUTILS_V1.MD', '../DAIMOS/INCLUDE/SYSCALL.H', AND THE DSH SOURCES.
DSH IS A NATIVE DAIMOS SHELL USING SIXBIT SOURCE TEXT AND RUN/WAIT PROCESS LAUNCH. IT IS NOT A POSIX SH PORT.

COMMAND MANUAL, -H HELP, OPTION-DESCRIPTION, AND COMPLETION METADATA ARE DEFINED
IN `USER/SIXMD.MD`.  DSH SHALL CONSUME THAT COMMON DESCRIPTION RATHER THAN KEEP
PER-COMMAND COMPLETION TABLES.

## NATIVE SHELL AND CORE COMMANDS
DATE: 2026-06-30
SCOPE: DAIMOS / DAIMON PDP-6 AND KA10 BASELINE

THIS DOCUMENT DEFINES THE FIRST NATIVE DAIMOS SHELL DIRECTION AND THE MINIMAL
CORE COMMAND SET THAT GROWS WITH IT.  THE UPLOADED 2.11BSD SHELL IS A BEHAVIOR
CHECKLIST, NOT SOURCE TO PORT LINE BY LINE.

THE NATIVE SHELL IS CALLED DSH.  DSH SOURCE TEXT, PATHS, KEYWORDS, VARIABLE
NAMES, AND COMMAND NAMES ARE PURE SIXBIT.  LOWERCASE, UTF-8, NUL-TERMINATED
C STRINGS, AND NON-SIXBIT BYTES ARE NOT VALID DSH SOURCE.

### 1. DESIGN RULES

'''TEXT
- NATIVE DAIMOS SHELL, NOT POSIX SH
- PURE SIXBIT SHELL LANGUAGE
- NO ASCII SCRIPT MODE
- FIXED ARENAS, NO SBRK
- RUN/WAIT, NOT FORK/EXEC
- READ-ONLY ROOT FIRST
- NO C STRINGS FOR PERSISTENT SHELL-LANGUAGE VALUES
- FEW SYSCALLS
- SMALL ENOUGH FOR 256K WORDS AND NO SWAPPING
'''

### 1.1 NATIVE NAMESPACE FOR EARLY USERLAND

DAIMOS NATIVE PATHS ARE NOT UNIX PATHS.  THE NATIVE NAMESPACE USES SHORT,
SIXBIT-FRIENDLY WORDS, USUALLY ONE WORD OF AT MOST SIX CHARACTERS.  THREE-LETTER
UNIX DIRECTORY NAMES ARE AVOIDED UNLESS THEY ARE COMMAND NAMES KEPT FOR USER
FAMILIARITY.

INITIAL NATIVE ROOT NAMES:

'''TEXT
/SYSTEM     MANDATORY BASE SYSTEM
/OPTION     INSTALLED OPTIONAL PACKAGES AND DISKSET CONTENTS
/HOME       USER HOMES
/TEMP       TEMPORARY STORAGE
'''

SYSTEM CONFIGURATION AND DEVICE NAMES:

'''TEXT
/CONFIG     REAL SYSTEM CONFIGURATION DIRECTORY
/DEVICE     DEVICE NAMESPACE VIEW
'''

NAMES DELIBERATELY NOT MANDATORY IN THE NATIVE ROOT:

'''TEXT
/BIN
/USR
/CMD
/MNT
/SYSTEM/BOOT
'''

BOOT STATE IS NOT PART OF THE ORDINARY FILESYSTEM NAMESPACE.  STAGE IMAGES,
BOOTSTRAP SECTORS, PAPER TAPE RECORDS, AND BOOT TABLES ARE MANIPULATED ONLY BY
EXPLICIT ADMIN TOOLS.  IF BOOT STATUS OR INSTALLATION TOOLS BECOME USER-VISIBLE,
THEY LIVE AS NORMAL COMMANDS, NOT AS EDITABLE FILES BELOW '/SYSTEM/BOOT'.

THE BASE SYSTEM AND OPTIONAL SOFTWARE USE PARALLEL TREES:

'''TEXT
/SYSTEM/INIT
/SYSTEM/EXEC
/SYSTEM/LIB
/SYSTEM/INCLUDE
/SYSTEM/MANUAL
/SYSTEM/SOURCE
/OPTION/EXEC
/OPTION/LIB
/OPTION/INCLUDE
/OPTION/MANUAL
/OPTION/SOURCE
/CONFIG/INITTAB
/CONFIG/PASSWD
'''

`/SYSTEM` HOLDS MANDATORY BASE-SYSTEM CONTENT.  `/OPTION` HOLDS OPTIONAL OR
NON-SYSTEM SOFTWARE WITH THE SAME INTERNAL LAYOUT.  `/CONFIG` IS THE REAL
SYSTEM-CONFIGURATION TREE, ANALOGOUS IN PURPOSE TO UNIX `/ETC`.

EVERY INSTALLED COMMAND IMAGE MUST HAVE A MANUAL PAGE.  THE ROOT IMAGE BUILDER
SHOULD REJECT COMMAND ENTRIES WITHOUT MATCHING MANUAL ENTRIES ONCE COMMAND-IMAGE
INSTALLATION IS AUTOMATED.

THE FIRST DSH SEARCH PATH IS:

'''TEXT
/SYSTEM/EXEC:/OPTION/EXEC
'''

UNIX-LIKE COMMAND NAMES ARE KEPT WHERE USEFUL:

'''TEXT
DSH TRUE FALSE ECHO CAT PWD STAT LS TEST [ SYSCTL DEVS MODS MOUNTS MAN PAGE
'''

THE DIRECTORY VOCABULARY IS DAIMOS-NATIVE; THE COMMAND VOCABULARY MAY REMAIN
UNIX-LIKE.

A LATER POSIX PERSONALITY PROVIDES UNIX PATHS AS SYNTHETIC COMPATIBILITY VIEWS.
'/BIN' MUST NOT BE A FIXED LINK TO ONE TREE.  IT IS A CONFIGURABLE SYNTHETIC
VIEW, OR EQUIVALENT PATH POLICY, OVER ALL CONFIGURED 'EXEC' ROOTS THAT THE POSIX
PERSONALITY WANTS TO EXPOSE.  '/SBIN', '/USR/BIN', '/DEV', '/ETC', '/TMP', AND
'/HOME' ARE PERSONALITY VIEWS, NOT NATIVE DAIMOS REQUIREMENTS.

NO ALWAYS-PRESENT ROOT MOUNT DIRECTORY EXISTS.  MOUNT POINTS ARE ORDINARY
DIRECTORIES CREATED BY POLICY.  USER-MOUNTABLE REMOVABLE STORAGE BELONGS BELOW
USER HOMES, FOR EXAMPLE:

'''TEXT
/HOME/ROMAN/MOUNTS/DT0
/HOME/ROMAN/MOUNTS/DT1
'''

THOSE HOME MOUNT POINTS ARE FOR DTFS DECTAPES.  TSFS IS A SEQUENTIAL TAPE/ARCHIVE
FILESYSTEM AND IS NOT A USER-HOME MOUNT FORMAT.

### 1.2 FIRST CONSOLE AND PAGER MODEL

CTY IS A REAL TELETYPE-STYLE CONSOLE, NOT A TERMINAL EMULATOR.  THE DEVICE
ITSELF RECEIVES AND TRANSMITS CHARACTERS, BUT THE NATIVE BOOTSTRAP SHELL DOES
NOT CROSS A BYTE-TEXT ABI.  THE KERNEL COOKED LINE DISCIPLINE PACKS CTY INPUT
DIRECTLY INTO AN S6REC RECORD; DSH RECEIVES THAT RECORD WITH 'SYS_cons_get6'.
DSH MUST NOT REQUIRE CURSOR ADDRESSING, SCREEN CLEARING, ANSI ESCAPES, CURSES,
OR A TERMINAL CAPABILITY DATABASE ON CTY.

THE FIRST INTERACTIVE CONSOLE IS THEREFORE TRANSCRIPT-ORIENTED:

'''TEXT
/SYSTEM/INIT OPENS CTY AS FD 0, FD 1, AND FD 2
/SYSTEM/INIT RUNS /SYSTEM/EXEC/DSH
DSH PRINTS A PROMPT
CTY PI DELIVERS INPUT TO THE KERNEL CONSOLE LINE DISCIPLINE
THE KERNEL COOKS ONE LINE DIRECTLY INTO S6REC
DSH FETCHES THE COMPLETE RECORD WITH SYS_cons_get6
DSH PARSES PACKED SIXBIT WORDS WITHOUT A CHAR * / BP9 TEXT BOUNDARY
DSH RUNS EXTERNAL COMMANDS WITH SYS_RUN AND SYS_WAIT
DSH PRINTS THE NEXT PROMPT
'''

KCORE OWNS THE RESIDENT CTY PI REGISTRATION.  AFTER KCORE REINITIALIZES THE
PDP-6 PI SYSTEM WITH 'pdp10_pi_init()', IT RECONNECTS CTY AT THE NATIVE CTY PI
LEVEL.  BOOTSTRAP CODE MUST NOT RELY ON A CTY PI REGISTRATION MADE BEFORE THAT
RESET.

A FIRST PAGER IS A LINE PAGER.  IT PRINTS FORWARD AND PAUSES AFTER A FIXED
NUMBER OF LINES.  IT DOES NOT CLEAR THE SCREEN OR MOVE THE CURSOR.  RICHER
TERMINAL HANDLING BELONGS TO LATER SERIAL TTY SUPPORT, NOT TO CTY.

SMALL-PROFILE LIMITS USED BY THE CURRENT IMPLEMENTATION:

'''TEXT
PARSE NODES PER COMMAND:        32
WORDS PER SIMPLE COMMAND:        8
VARIABLES:                      16
FUNCTION DEFINITIONS:            4
FUNCTION BODY NODES:            16
FUNCTION CALL DEPTH:             4
BACKGROUND CHILDREN:             4
SCRIPT TOKEN ACCUMULATOR:       64 TOKENS
LOOP GUARD:                     64 ITERATIONS
'''

### 2. SIXBIT SYNTAX REPLACEMENTS

STANDARD SIXBIT DOES NOT ENCODE LOWERCASE LETTERS, BACKQUOTE, BRACES, VERTICAL
BAR, OR TILDE.  DSH USES THESE REPLACEMENTS:

'''TEXT
UNIX-LIKE FORM       DAIMOS DSH FORM
A ! B                A ! B
'CMD'                $(CMD)
$(NAME)              $[NAME]
( LIST; )            BEGIN LIST END
-/FILE               $HOME/FILE
LOWERCASE INPUT      SYNTAX ERROR
'''

'!' IS RESERVED FOR PIPES.  LOGICAL OPERATORS ARE WORDS:

'''TEXT
AND
OR
NOT
'''

### 3. GRAMMAR

CURRENT GRAMMAR:

'''TEXT
SCRIPT  := LIST
LIST    := ANDOR ( ; ANDOR )
ANDOR   := NOTCMD ( AND NOTCMD ! OR NOTCMD )
NOTCMD  := [ NOT ] COMMAND
COMMAND := SIMPLE ! IF ! FOR ! WHILE ! UNTIL ! GROUP ! DEF ! CASE
SIMPLE  := WORD ( WORD ) ( REDIR )
REDIR   := < WORD ! > WORD ! >> WORD
IF      := IF LIST THEN LIST [ ELSE LIST ] FI
FOR     := FOR NAME IN WORDS DO LIST DONE
WHILE   := WHILE LIST DO LIST DONE
UNTIL   := UNTIL LIST DO LIST DONE
GROUP   := BEGIN LIST END ! ( LIST )
DEF     := DEF NAME DO LIST DONE
CASE    := CASE WORD IN WORD THEN LIST [ ELSE LIST ] ESAC
'''

RESERVED LATER GRAMMAR:

'''TEXT
PIPELINE := COMMAND ( ! COMMAND )
SUBST    := $( LIST )
'''

PARENTHESES GROUP COMMANDS IN THE CURRENT SHELL; THEY DO NOT CREATE A SUBSHELL
AND DO NOT CLONE THE SHELL.

### 4. BUILTIN POLICY

ONLY COMMANDS THAT MUST MODIFY CURRENT SHELL STATE STAY RESIDENT IN DSH.
NORMAL UTILITIES ARE EXTERNAL PROGRAMS, EVEN IF THEY ARE TINY.

SHELL BUILTINS:

'''TEXT
EXIT      LEAVE SHELL OR HALT INIT SHELL
SET       SET ONE SHELL VARIABLE
READ      READ ONE LINE INTO A SHELL VARIABLE
SHIFT     SHIFT POSITIONAL ARGUMENTS
RETURN    RETURN FROM A SHELL FUNCTION
SOURCE    READ COMMANDS INTO THE CURRENT SHELL
.         ALIAS FOR SOURCE
WAIT      WAIT FOR A TRACKED BACKGROUND CHILD
'''

MANUAL TEXT POLICY:

'''TEXT
/SYSTEM/MANUAL/DSH
'''

LONG MANUAL OR USAGE TEXT DOES NOT LIVE IN THE RESIDENT SHELL BINARY.  RESIDENT
DSH PRINTS ONLY SHORT HUMAN-READABLE DIAGNOSTICS SUCH AS '?ERR SET', '?ERR
PIPE', OR '?ERR SUBST'.  'MAN DSH', OR A FUTURE USAGE READER, READS THE MANUAL
PAGE FROM '/SYSTEM/MANUAL/DSH'.  THE FILE IS DAIMOS SIXBIT TEXT; HOST-SIDE
COPIES MAY BE REPRESENTED AS UPPERCASE ASCII ONLY FOR REPOSITORY CONVENIENCE.

EXTERNAL COMMANDS, NOT SHELL BUILTINS:

'''TEXT

'TEST' AND '[' ARE EXTERNAL COMMAND NAMES.  THEY ARE NOT PARSER MAGIC AND NOT
RESIDENT BUILTINS.  THE HOST TESTS MAY MOCK THEM, BUT THE TARGET SHELL SHOULD
LAUNCH THEM LIKE ANY OTHER COMMAND.

COMMAND LOOKUP ORDER:

'''TEXT
1. SHELL BUILTIN

3. ABSOLUTE PATH

'''

THIS KEEPS SHELL-STATE COMMANDS RESIDENT, LETS SCRIPTS OVERRIDE EXTERNAL
COMMANDS WITH FUNCTIONS, AND AVOIDS PATH SCANS WHEN THE COMMAND CONTAINS '/'.

### 5. STRING AND PATHNAME POLICY

DSH VALUES ARE COUNTED SIXBIT STRINGS WHERE PERSISTENT.

'''TEXT
WORD 0: CHARACTER COUNT
WORD 1..N: SIX PACKED SIXBIT CHARACTERS PER WORD
'''

INTERACTIVE SOURCE LINES USE THE KERNEL S6REC TEXT RECORD FORM: A RECORD HEADER
WORD CARRIES THE TEXT/LINE STATE AND CHARACTER COUNT, FOLLOWED BY SIX PACKED
SIXBIT CHARACTERS PER PAYLOAD WORD.  THE NATIVE DSH PARSER CONSUMES THAT RECORD
DIRECTLY.

THE RESIDENT SHELL PARSER/EVALUATOR DOES NOT ACCEPT C STRINGS.  IN PARTICULAR,
THE NATIVE CONSOLE, COMMAND, PATH, ENVIRONMENT, AND BOOTSTRAP PROFILE TEXT
BOUNDARIES MUST NOT FALL BACK TO 'char *' OR BP9 TEXT.  HOST TESTS AND THE HOST
HARNESS MAY USE A BOUNDARY CONVERTER TO TURN REPOSITORY TEXT INTO PACKED SIXBIT
RECORDS, BUT THAT CONVERTER IS NOT A RESIDENT DSH TEXT INTERFACE.

### 6. RUN/WAIT V1 MODEL

DSH NEVER CLONES ITSELF TO LAUNCH AN EXTERNAL COMMAND.

'''TEXT
SHELL PARSES ARGV
SHELL RESOLVES COMMAND PATH
SHELL CALLS RUN
FOREGROUND COMMAND: SHELL CALLS WAIT
BACKGROUND COMMAND: SHELL STORES RETURNED PID
SHELL STORES LOW 8-BIT STATUS IN $?
'''

SMALL READ-ONLY USERLAND SYSCALLS ARE NOW:

'''TEXT
SYS_RUN
SYS_WAIT
SYS_SEEK
SYS_STAT
'''

STILL DEFERRED SYSCALLS:

'''TEXT
SYS_GETDENTS
SYS_DUP
SYS_CHDIR
SYS_PIPE
HANDLE-MAP SYSCALL
'''

RUN V1 PASSES ONLY:

'''TEXT
PATH
ARGV
ARGC
FLAGS
'''

NO ENVIRONMENT IS PASSED IN RUN V1.  EXPORT IS DEFERRED.

NO HANDLE MAP IS PASSED IN RUN V1.  CHILDREN INHERIT FD0/FD1/FD2.  REDIRECTION
IS PARSED, BUT EXECUTION RETURNS STATUS 126 UNTIL A SMALL HANDLE-MAP DESIGN IS
WORTH THE RESIDENT COST.

THE PRECISE RUN/WAIT ABI IS IN THIS DOCUMENT AND 'INCLUDE/SYSCALL.H'.

### 7. STATUS CONVENTION

'''TEXT
0       SUCCESS
1       FALSE OR ORDINARY COMMAND FAILURE

KERNEL WAIT STATUS RESERVES HIGHER BITS FOR LOADER AND SIGNAL-LIKE COMPLETION,
BUT DSH V1 STORES ONLY THE LOW 8 BITS IN '$?'.

### 8. BACKGROUND COMMANDS

'CMD &' CALLS RUN WITH 'SYS_RUN_F_BG'.  IF RUN SUCCEEDS, DSH STORES THE RETURNED
PID IN A FOUR-ENTRY TABLE.

'''TEXT
WAIT      WAIT FOR THE OLDEST TRACKED BACKGROUND CHILD
WAIT PID  WAIT FOR ONE MATCHING TRACKED CHILD
'''

NO JOB NAMES, JOB-CONTROL TERMINAL HANDLING, OR PROCESS GROUPS EXIST IN V1.

### 3. SYS_RUN

CALL CONVENTION:

'''TEXT
AC1 = SYS_RUN
AC2 = USER ADDRESS OF STRUCT SYS_RUN_ARGS
AC1 = RESULT
'''

RESULT:

'''TEXT
AC1 > 0    CHILD PID
AC1 < 0    NEGATIVE ERRNO-STYLE FAILURE
'''

'STRUCT SYS_RUN_ARGS':

'''C
STRUCT SYS_RUN_ARGS (
        KWORD_T         PATH;
        KWORD_T         ARGV;
        UNSIGNED INT    ARGC;
        UNSIGNED INT    FLAGS;
);
'''

FIELD MEANING:

'''TEXT
PATH   USER ADDRESS OF COUNTED SIXBIT EXECUTABLE PATH
ARGV   USER ADDRESS OF VECTOR OF COUNTED SIXBIT STRING POINTERS
ARGC   NUMBER OF ARGV ENTRIES
FLAGS  SYS_RUN_F_WAITABLE OR SYS_RUN_F_BG
'''

THE ARGV VECTOR IS SIZED BY ARGC AND IS NOT NUL-TERMINATED.

NO ENVIRONMENT IS PASSED IN RUN V1.  EXPORT IS DEFERRED UNTIL A LATER ABI
EXPLICITLY PAYS FOR IT.

NO HANDLE MAP IS PASSED IN RUN V1.  THE CHILD INHERITS THE CURRENT STANDARD
HANDLES:

'''TEXT
FD0 STDIN
FD1 STDOUT
FD2 STDERR
'''

REDIRECTION IS PARSED BY DSH BUT CANNOT EXECUTE THROUGH SYS_RUN V1.  THE SHELL
RETURNS STATUS 126 FOR REDIRECTION UNTIL A SMALL HANDLE-MAP DESIGN IS JUSTIFIED.

### 6. BACKGROUND CHILDREN

DSH KEEPS A VERY SMALL FIXED TABLE OF BACKGROUND PIDS.

'''TEXT
DSH_BG_MAX_CHILDREN = 4
'''

'CMD &' CALLS SYS_RUN WITH 'SYS_RUN_F_BG'.  IF RUN SUCCEEDS, DSH STORES THE
RETURNED PID IN THE TABLE.  IF THE TABLE IS FULL, THE SHELL RETURNS STATUS 2.

'WAIT' WAITS FOR THE OLDEST STORED CHILD.

'WAIT PID' WAITS FOR THE MATCHING STORED PID.

NO JOB NAMES, PROCESS GROUPS, TERMINAL HANDOFF, OR JOB-CONTROL SYNTAX EXIST IN
V1.

'INCLUDE/EXEC.H'.

IMPLEMENTED NOW:

'''TEXT
DEX0R CONSTANTS

### 9. STARTUP REGISTERS

'SYS_RUN' STARTS A DEX0R NATIVE1 PROCESS WITH THE DEX0R ARGV STARTUP ABI:

'''TEXT
AC1 = ARGC
AC2 = ARGV POINTER, OR 0 WHEN ARGC IS 0
AC3 = 0, RESERVED
PC  = DEX0R ENTRY ADDRESS
SP  = STACK POINTER AFTER THE ARGV STARTUP BLOCK
'''

THE ARGV VECTOR CONTAINS 'ARGC' ABSOLUTE USER ADDRESSES OF COUNTED PACKED
SIXBIT STRINGS.  IT IS NOT ZERO-TERMINATED.  RUN V1 HAS NO ENVIRONMENT VECTOR.

'''TEXT
