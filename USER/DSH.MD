## LANGUAGE AND MEMORY RULES

- DSH IS NATIVE DAIMOS SOFTWARE AND USES RUN/WAIT RATHER THAN FORK/EXEC.
- MEMORY USE IS BOUNDED; CORE SHELL DATA STRUCTURES DO NOT REQUIRE UNBOUNDED
  HEAP GROWTH.
- ORDINARY UTILITIES ARE EXTERNAL PROGRAMS; BUILTINS ARE KEPT FOR OPERATIONS
  THAT MUST MODIFY SHELL STATE OR WHERE MEASUREMENT JUSTIFIES RESIDENCY.
- PIPELINE OPERATOR: `!`.
- LOGICAL OPERATORS: `AND`, `OR`, `NOT`.
- BACKGROUND EXECUTION: `COMMAND &`.
- COMPLETION IS ADVISORY AND MUST NEVER PREVENT COMMAND EXECUTION.
- SIXMD MANUAL METADATA IS THE AUTHORITATIVE HELP/GETOPT/COMPLETION DESCRIPTION
  ONCE INSTALLATION TOOLING ENFORCES IT.

THE CURRENT ADMINISTRATIVE BUILTIN `TTYOUT` CONTROLS THE KERNEL'S DETACHABLE
TTY OUTPUT ROUTE WITHOUT CHANGING THE LOGICAL INPUT LINE.  `TTYOUT N` REPORTS
THE EFFECTIVE SINK; `TTYOUT N DPY`, `TTYOUT N CTY`, OR `TTYOUT N M` SELECT AN
EXPLICIT SINK; `TTYOUT N NATIVE` RESTORES THE HISTORICAL INPUT/OUTPUT PAIR.
CHANGING A ROUTE IS ROOT-ONLY BECAUSE THE ROUTE IS TERMINAL-GLOBAL AND
PERSISTS ACROSS LOGIN SESSIONS.  THIS IS INTENDED PRIMARILY FOR PAIRING CTY,
DCS, OR GE KEYBOARD INPUT WITH THE TYPE-340 DISPLAY.
