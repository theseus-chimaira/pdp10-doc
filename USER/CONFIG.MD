# DAIMOS USERSPACE CONFIGURATION FILES

DATE: 2026-09-30

DAIMOS USERSPACE USES TWO SMALL TEXT CONFIGURATION GRAMMARS.  BOTH ARE READ
FROM NORMAL S6REC TEXT FILES AND ARE DESIGNED FOR STREAMING, ALLOCATION-FREE
PARSING ON THE 32K PDP-6 BASELINE.

## FIELD RECORDS

FIELD RECORDS ARE COLON-DELIMITED:

    FIELD:FIELD:FIELD

THE GENERIC TEXT LIBRARY ONLY SPLITS THE RECORD.  THE CONSUMING APPLICATION
DEFINES THE NUMBER, TYPE, RANGE, AND MEANING OF THE FIELDS.  EMPTY FIELDS ARE
SIGNIFICANT, AS IN THE EMPTY PASSWORD FIELD HERE:

    ROOT::0:0:/:/SYSTEM/EXEC/DSH

CURRENT USERS ARE /CONFIG/PASSWD, /CONFIG/FSTAB, AND /CONFIG/INITTAB.

THE CURRENT FSTAB V1 RECORDS USED BY MOUNTALL ARE:

    MEMFS:/EXISTING/MOUNT/POINT:WORDS
    MEMFS:/EXISTING/MOUNT/POINT:WORDS:PERSIST
    D6FS:D6SET1:/EXISTING/MOUNT/POINT
    D6FS:D6SET1:/EXISTING/MOUNT/POINT:OPTIONAL

THE NORMAL FULL PROFILE USES `/TEMP` FOR MEMFS AND DECLARES
`D6FS:D6SET1:/SCRATCH:OPTIONAL`.  `/SCRATCH` IS AN ORDINARY DIRECTORY IN THE
ROOT NAMESPACE; WHEN THE SECONDARY FOUR-DRM D6FS SET IS PRESENT, MOUNTALL
MOUNTS IT READ-WRITE THERE.  `OPTIONAL` MEANS ABSENCE OR INVALID SECONDARY
MEDIA DOES NOT FAIL BOOT.  D6SET0 REMAINS THE ROOT SET.

## KEY/VALUE RECORDS

SIMPLE POLICY FILES MAY USE:

    KEY = VALUE
    KEY = VALUE VALUE VALUE

THE RIGHT-HAND SIDE IS ZERO OR MORE SPACE-SEPARATED VALUES.  ZERO VALUES ARE
VALID, SO AN EMPTY SET DOES NOT REQUIRE A SPECIAL SPELLING:

    OPTIONAL =

THERE ARE NO SECTIONS, QUOTING, ESCAPES, CONTINUATIONS, SUBSTITUTIONS, OR
INTERPOLATION.  ADD SUCH FEATURES ONLY WHEN A CONCRETE DAIMOS CONSUMER NEEDS
THEM.

THE FIRST CONSUMER IS /CONFIG/SYSTEM.  ITS V1 STORAGE POLICY IS:

    SWAP = AUTO
    LOGSTORE = AUTO

EACH KEY ACCEPTS AUTO OR OFF.  AUTO ENABLES THE RESERVATION/SERVICE DISCOVERED
AND PREPARED BY KINIT WHEN ONE EXISTS; OFF LEAVES IT INACTIVE.  A MISSING
/CONFIG/SYSTEM RETAINS AUTO FOR BOTH KEYS FOR COMPATIBILITY.  UNKNOWN KEYS,
DUPLICATE KEYS, EXTRA VALUES, AND UNKNOWN VALUES ARE INVALID.

KINIT CONTINUES TO OWN ROOT/STORAGE DISCOVERY AND MRES INSTALLATION.  PID-1
INIT OWNS THE ADMINISTRATIVE ACTIVATION MASK.  SWAP OFF PREVENTS NEW PROCESS
OR MEMFS SWAP ALLOCATIONS AND DISABLES PERSISTENT MEMFS SNAPSHOT/RESTORE.
LOGSTORE OFF PREVENTS NEW LOGSTORE APPENDS; THE EXISTING RAW RANGE MAY STILL
BE INSPECTED OR DRAINED.

## COMMON LEXICAL RULES

- ONE PHYSICAL S6REC TEXT LINE IS ONE CONFIGURATION RECORD.
- BLANK LINES ARE IGNORED.
- A LINE WHOSE FIRST NON-WHITESPACE CHARACTER IS # IS A COMMENT.
- SPACE AND TAB ARE TRIMMED AROUND COLON FIELDS, KEYS, AND THE COMPLETE
  RIGHT-HAND SIDE.
- KEY/VALUE LIST MEMBERS ARE SEPARATED BY ONE OR MORE SPACES OR TABS.
- INLINE COMMENTS ARE NOT DEFINED; # IS ORDINARY DATA AFTER A RECORD STARTS.

FORMAT/VERSION COMMENTS SUCH AS # DAIMOS FSTAB V1 ARE DOCUMENTATION, NOT
GENERIC PARSER MAGIC.  A CONSUMER THAT REQUIRES A VERSION FIELD MUST DEFINE
AND VALIDATE THAT FIELD ITSELF.

## LIBRARY CONTRACT

userland/libc/text.c OWNS BOTH S6REC LINE READING AND THE COMMON
CONFIGURATION TOKENIZERS.  u_text_fields() AND u_text_key() MODIFY A
CALLER-PROVIDED LINE BUFFER AND RETURN POINTERS INTO THAT BUFFER.  THEY DO NOT
ALLOCATE, COPY FIELD CONTENT, BUILD A CONFIGURATION TREE, OR INTERPRET
APPLICATION TYPES.

THIS KEEPS TEXT DECODING, WHITESPACE HANDLING, COMMENT HANDLING, AND TOKEN
BOUNDARIES SHARED WHILE LEAVING POLICY AND VALIDATION WITH EACH CONSUMER.
