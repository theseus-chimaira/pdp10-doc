# NATIVE MAKE RECURSION SCRATCH (2026-11-03 V1054)

NATIVE MAKE STORES PARSED GRAPH RECORDS IN COMPACT INDEXED TABLES AND
USES A SEPARATE SCRATCH RECORD FOR IMPLICIT-RULE LOOKUPS AT EACH ACTIVE
RECURSION DEPTH. EACH RECORD HOLDS AN IMPLICIT RULE ID, SOURCE NAME,
AND STEM, WITH A MAXIMUM RECURSION DEPTH OF 32 (33 SLOTS).

## IMPLEMENTED MEMORY LAYOUT

THE OCTOBER V1 EXPERIMENT CORRECTLY IDENTIFIED EXCESSIVE STACK/HEAP
USAGE FROM KEEPING ALL IMPLICIT RULE SCRATCH RECORDS AT ONCE. A LATER
PRODUCTION MAKE VERSION ALREADY MOVED THAT SCRATCH OUT OF THE STRING
ARENA, BUT STILL ALLOCATED 33 RECORDS UNCONDITIONALLY AFTER PARSING.

V1054 NOW ALLOCATES A RECORD WHEN A RECURSION DEPTH IS FIRST REACHED,
THEN REUSES THE SAME RECORD ON SUBSEQUENT VISITS TO THAT DEPTH. THE
RECORD POINTERS REMAIN STABLE DURING DEEPER CALLS. ALLOCATION FAILURE
RETURNS THE EXISTING `IMPLICIT SCRATCH EXHAUSTED` ERROR. THE EXISTING
NATIVE ASSEMBLER MEMCPY REMAINS IN USE; THE OLD EXPERIMENTAL C MEMCPY
IS NOT ADDED.

KCC CODE GENERATION CONFIRMS 212 TARGET C CHARACTERS PER RECORD,
CORRESPONDING TO 53 PDP-6 WORDS. THE OLD 33-RECORD SLAB HOLDS 1749
WORDS. AT SIX VISITED DEPTHS THE NEW SIX RECORDS HOLD 318 WORDS,
PLUS SIX HEAP HEADERS AND A STATIC 33-POINTER ARRAY. WITH TWO-WORD
HEAP HEADERS THIS IMPLIES ABOUT 1389 FEWER TOTAL PROCESS WORDS THAN
THE OLD SLAB PLUS ITS HEADER. THIS IS A CALCULATED ALLOCATION
COMPARISON, NOT A MEASUREMENT OF REAL PEAK RESIDENT MEMORY.

LINKED NATIVE KCC MAKE IMAGE (OCTAL PDP-6 WORD COUNTS):

    CONFIGURATION          TEXT      BSS
    ORIGINAL SLAB          025124    001526
    LAZY PER-DEPTH         025116    001566

TEXT FALLS BY SIX WORDS; STATIC BSS GROWS BY 32 WORDS FOR THE
POINTER ARRAY. AT MAXIMUM DEPTH, 33 SEPARATE ALLOCATOR HEADERS
AND THE POINTER ARRAY CAN COST 96 MORE WORDS THAN THE OLD SINGLE
SLAB. THE PEAK-MEMORY TRADEOFF MUST BE RECHECKED FOR VERY DEEP BUILDS.

## TEST COVERAGE

THE TESTKIT TARGET `TEST-DAIMOS-MAKE-LAZY-DEPTH-V1054` REQUIRES A
FRESH 256K FULL-PROFILE BOOT IMAGE AND USES ISOLATED SIMH MEDIA.
ITS TWO NATIVE GUEST PROBES VERIFY A SIX-LEVEL DEPENDENCY CHAIN
AND DEPENDENCY CYCLE REJECTION. BOTH PASS ON THE LAZY IMPLEMENTATION
AND ON AN UNMODIFIED CONTROL IMAGE. THE TARGET ALSO CHECKS THE
SOURCE CONTRACT AND REJECTS THE OLD BULK ALLOCATOR. KCC LINK PASSES.

THIS DOES NOT REPLACE A FULL NATIVE `MAKE ALL` SELF-HOSTING RUN,
HEAP-PEAK MEASUREMENT, OR 32K-SPECIFIC ACCEPTANCE. THOSE REMAIN
OPEN. THE CHANGE IS USERLAND-ONLY: KCORE OPTIMIZATION IS DEFERRED.
