## 2. ROOT CAUSE AND CORRECTION

SIMH `PDP10/PDP6_DTC.C` HAD ONE GLOBAL `DTSB` STATUS WORD, BUT ALL MOVING
TRANSPORT EVENT HANDLERS MODIFIED IT, EVEN WHEN THEY WERE NOT THE CURRENTLY
SELECTED UNIT.  THEIR END-OF-TAPE AND COMPLETION FLAGS COULD INTERRUPT OR
TERMINATE THE ACTIVE TRANSPORT'S TYPE-136 DATA TRANSFER.

THE FIX TRACKS `DTC_SELECTED_UNIT` THROUGH TYPE-551 COMMANDS.  FOR
NONSELECTED TRANSPORTS, THE EVENT ROUTINE ADVANCES MECHANICAL POSITION USING
LOCAL INACTIVE STATUS ONLY; IT CANNOT CHANGE THE SHARED STATUS, ACCESS THE
TYPE-136 CHANNEL, OR POST A CONTROLLER INTERRUPT.  THE SELECTED TRANSPORT
USES THE ORIGINAL SHARED STATUS DIRECTLY.  THE CONO STATUS-A LATCH NOW
PRESERVES UNIT-SELECT BITS, AND ADDITIONAL READ-ONLY REGISTERS EXPOSE THE
HANDSHAKE FOR DIAGNOSIS.

THE FRESH SOURCE-TREE SIMH REBUILD ALSO DISCOVERED THAT `OPCOUNT` HAD BEEN
PLACED BEFORE `CPU PC`, SO `GO 020` DID NOT START THE PDP-6 READ-IN LOOP.
THE KNOWN PC-FIRST ORDER WAS RESTORED.

SIMH COMMIT: `8361359` — `Fix PDP-6 Type-551 selected transport isolation
and PC-first bootstrap v34`.
