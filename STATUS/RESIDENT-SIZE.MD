# DAIMOS RESIDENT-SIZE STATUS

DATE: 2026-09-18

## CURRENT ACCEPTANCE ACCOUNTING

THE CURRENT SHRINK TARGET IS A 14K TOTAL KERNEL FOOTPRINT.  LOW CORE FROM
000000 THROUGH ABOUT 000060 CONSUMES WORDS OUTSIDE THE KCORE+MRES LINK TOTAL,
SO THE CURRENT MEASURABLE ACCEPTANCE GATE IS:

    KCORE + MRES <= 14288 DECIMAL WORDS

THE CURRENT FRESH KCC FULL-BOOT MEASUREMENT IS:

    KCORE           8597 DECIMAL WORDS
    MRES             5642 DECIMAL WORDS
    KCORE+MRES      14239 DECIMAL WORDS
    PERMANENT_LAST  033716 OCTAL (14286 DECIMAL ADDRESS)

THE 14288-WORD SHRINK GATE IS MET BY 49 KCORE+MRES WORDS.  THE CURRENT
PERMANENT HIGH-WATER ADDRESS IS ALSO 49 WORDS BELOW THE TEMPORARY 14K
SHRINK-PASS LAST-ADDRESS CEILING 033777.

THE HARD ARCHITECTURAL LIMIT REMAINS BELOW 16K WORDS INCLUDING FIXED RESIDENT
AND IRREDUCIBLE SCRATCH KERNEL MEMORY.  040000 OCTAL IS THE ONE-PAST-16K
ADDRESS, SO THE CURRENT PERMANENT HIGH-WATER LEAVES 2097 ADDRESSABLE WORDS
BEFORE THAT BOUNDARY.  THIS IS A PLANNING GAP, NOT 2097 WORDS THAT MAY ALL BE
SPENT ON CODE: IRREDUCIBLE SCRATCH AND SAFETY HEADROOM MUST ALSO FIT.

ELASTIC D6FS CACHE BLOCKS BORROWED FROM MANAGED CORE ARE NOT FIXED KERNEL-IMAGE
MEMORY AND ARE RECLAIMED FOR PROCESSES/MODULES UNDER PRESSURE.  CACHE CODE,
NONRECLAIMABLE METADATA, AND FIXED SCRATCH STILL COUNT TOWARD THE LIMIT.

## COMPILER RULE

KCC IS THE ACCEPTANCE COMPILER.  GCC HAS HISTORICALLY GENERATED A SMALLER
KERNEL, AND GCC MEASUREMENTS MAY REMAIN USEFUL COMPILER-QUALITY DATA, BUT A GCC
IMAGE MUST NOT BE USED TO PASS A KCC SIZE GATE.

OLDER 11500-, 11999-, 12288-, 12-KIWORD, 13312-, AND 13-KIWORD TARGETS WERE
EARLIER DEVELOPMENT MILESTONES.  THEY ARE NOT ACTIVE ACCEPTANCE LIMITS.
DETAILED HISTORICAL SIZE SWEEPS REMAIN AVAILABLE IN GIT HISTORY.

## REPORTING REQUIREMENTS

EACH MATERIAL SIZE CHANGE SHOULD RECORD:

- COMPILER AND RELEVANT FLAGS;
- KCORE WORDS;
- EACH NORMAL FULL-BOOT MRES PACKAGE;
- KCORE+MRES TOTAL;
- LOW-CORE OR OTHER RESIDENT/SCRATCH COMPONENTS NEEDED TO INTERPRET THE TOTAL;
- PERFORMANCE CHANGE WHEN SIZE WAS TRADED AGAINST EXECUTION SPEED.

THE TESTKIT SHOULD ENFORCE 14288 UNTIL THE CURRENT KCC SHRINK/ACCEPTANCE PASS
IS FORMALLY CLOSED.  AFTER CLOSURE, 14239 REMAINS THE RECORDED GROWTH BASELINE
AND THE TESTKIT MUST KEEP THE BELOW-16K TOTAL ARCHITECTURAL SANITY BOUND AS THE
HARD LIMIT FOR APPROVED NEW FIXED KERNEL WORK.
