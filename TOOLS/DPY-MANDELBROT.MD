# DPY MANDELBROT STANDALONE INIT

'STANDALONE/MANDEL_INIT.S' IS A STANDALONE INIT REPLACEMENT FOR THE PDP-6
BOOT IMAGE.  IT INITIALIZES DPY DEVICE '0130', THEN STREAMS A PRECOMPUTED
1024X1024X1 MANDELBROT IMAGE TO THE TYPE 340 DISPLAY THROUGH THE PDP-6 TYPE
344 'DATAO' INTERFACE.

THE DISPLAY IS VECTOR HARDWARE, SO THE IMAGE IS NOT EMITTED AS ONE MILLION
SINGLE POINTS.  'TOOLS/MKMANDEL_DPY_INIT.PY' THRESHOLDS THE MANDELBROT SET AND
COMPRESSES LIT PIXELS INTO HORIZONTAL RUNS.  EACH RUN BECOMES ONE OR MORE TYPE
340 VECTOR SEGMENTS, WITH A MAXIMUM VECTOR DELTA OF 127 PIXELS BECAUSE THE
TYPE 340 VECTOR INSTRUCTION CARRIES SEVEN MAGNITUDE BITS PER AXIS.

THE CHECKED-IN GENERATED IMAGE USES:

- GEOMETRY: 1024X1024X1
- COMPLEX PLANE: X = -2.4..1.0, Y = -1.5..1.5
- ITERATION LIMIT: 64
- LIT PIXELS: 161164
- HORIZONTAL RUNS: 2972
- VECTOR/POINT SEGMENTS: 3826

TO USE IT IN THE BOOT IMAGE GENERATOR:

'''SH
MAKE PDP10_PREFIX=/PATH/TO/CROSS PDP6_CONSOLE=DPY \
    PDP6_ROOT_INIT_ASM=STANDALONE/MANDEL_INIT.S PDP6-BOOT-IMAGES
'''

TO REGENERATE THE ASSEMBLY:

'''SH
PYTHON3 TOOLS/MKMANDEL_DPY_INIT.PY STANDALONE/MANDEL_INIT.S
'''

TO TEST IT:

'''SH
MAKE PDP10_PREFIX=/PATH/TO/CROSS MANDEL-INIT-TEST
'''

## ENCODING NOTE

THE PROGRAM ENCODES TYPE 340 POINT/VECTOR HALFWORDS ACCORDING TO THE SIMULATOR
IMPLEMENTATION IN 'SIMS/PDP10/DISPLAY/TYPE340.C'.  IN PARTICULAR, THE POINT-MODE
Y-COORDINATE SELECTOR IS BIT 1, OCTAL '0200000'.  THIS DIFFERS FROM THE CURRENT
'DPY_MAKE_POINT_COORD()' HELPER, WHICH USES OCTAL '040000'; THAT HELPER SHOULD
BE FIXED SEPARATELY SO THE KERNEL DPY DRIVER AND STANDALONE IMAGE GENERATOR USE
THE SAME TYPE 340 BIT LAYOUT.
