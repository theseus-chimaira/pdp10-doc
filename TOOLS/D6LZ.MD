# @?D6LZ - COMPRESS DAIMOS 36 BIT WORD STREAMS

## @?OPTIONS

### @?-X - COMPRESS A DXR EXECUTABLE
VALIDATE AN UNCOMPRESSED DXR EXECUTABLE, COMPRESS ITS LOAD IMAGE, PRESERVE ITS
RELOCATION BITMAP, DXR2 TEXT METADATA, PURE STATE, AND RT_REQUIRED STATE, AND SET THE DXR COMPRESSED FLAG.
THE HOST TOOL ALSO ACCEPTS LOWERCASE -@X.

## @?OPERANDS

### @?SOURCE FILE
INPUT 36 BIT WORD-CONTAINER FILE.

### @?DEST FILE
OUTPUT WORD-CONTAINER FILE.

## DESCRIPTION

D6LZ IS THE HOST COMPRESSOR FOR THE DAIMOS D6LZ36 FORMAT.  HOST WORD FILES USE
ONE 36 BIT PDP-10 WORD IN THE LOW BITS OF EACH EIGHT BYTE LITTLE ENDIAN
CONTAINER WORD.

WITHOUT -X, D6LZ COMPRESSES THE COMPLETE INPUT AS A RAW D6LZ36 STREAM.
WITH -X IT WRITES A FLAGGED DXR2 EXECUTABLE.  THE KERNEL NEVER INFERS
EXECUTABLE COMPRESSION FROM FILE CONTENT.

THE STREAM USES 36 TOKEN CONTROL GROUPS, A 128 WORD HISTORY WINDOW, AND MATCH
LENGTHS FROM 3 THROUGH 130 WORDS.

## @?EXIT STATUS

### @?0 - COMPRESSION SUCCEEDED
### @?1 - INVALID INPUT OR OUTPUT FAILURE
