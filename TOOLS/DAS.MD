# @?DAS - DAIMOS PDP-6 AND PDP-10 ASSEMBLER

## DESCRIPTION

DAS ASSEMBLES PDP-6 AND PDP-10 SOURCE FOR DAIMOS.  IT WRITES DIRECTLY
LOADABLE DXR IMAGES AND, WHERE THE DOBJ PATH IS INCLUDED, DOBJ RELOCATABLE
OBJECTS.  THE PUBLIC COMMAND USES ONE UPPERCASE SHORT-OPTION INTERFACE.

DAS IS DESIGNED FOR SMALL RESIDENT MEMORY.  SYMBOLS, LITERALS, MACRO AND
REPETITION TEXT, AND PHASE RECORDS USE BOUNDED RESIDENT STATE WITH SCRATCH
BACKING.  THE NORMAL DXR ASSEMBLER RUNS PASS 1 AND PASS 2 AS SEPARATE PHASES.

THE NORMAL DXR PATH USES TWO SEQUENTIAL PHASES CONNECTED BY THE VERSIONED
DASIR2 INTERMEDIATE FORMAT, KEEPING RESIDENT MEMORY BOUNDED.

## INVOCATION

THE PUBLIC COMMAND LINE USES UPPERCASE SHORT OPTIONS:

    DAS [-@C] [-@B OR -@K] [-@A OR -@S] [-@F] [-@P] [-@M] [-@L FILE] -@O FILE SOURCE

A TYPICAL INVOCATION IS:

    DAS -@F -@O KERNEL.DXR KERNEL.S

OPTIONS ARE:

- -@C EMITS DOBJ INSTEAD OF DXR.
- -@B RESTRICTS INSTRUCTIONS TO THE BASE PDP-6 AND KA10 SET.
- -@K ENABLES BASE KERNEL MODE AND PERMITS THE REQUIRED I/O INSTRUCTIONS.
- SOURCE STORAGE FORMAT IS DETECTED AUTOMATICALLY.  HOST DAS ACCEPTS ASCII OR
  S6REC WITHOUT AN INPUT-FORMAT OPTION; RESIDENT DAS READS NATIVE S6REC TEXT.
- -@A FORCES ORDINARY ASCII SOURCE AND -@S FORCES S6REC SOURCE.  THESE ARE
  COMPATIBILITY/DIAGNOSTIC OVERRIDES, NOT NORMAL BUILD REQUIREMENTS.
- -@F ENABLES THE PEEPHOLE AND FOLDING OPTIMIZER.
- -@P USES A PIPE BETWEEN DXR PHASES INSTEAD OF A PHASE FILE.
- -@M PRINTS MEMORY AND WORK STATISTICS.
- -@L FILE WRITES A LABEL MAP.
- -@O FILE SELECTS THE OUTPUT FILE.

DAS USES UPPERCASE SHORT OPTIONS ONLY.  -@O ALWAYS SELECTS THE OUTPUT FILE
AND -@F ALWAYS ENABLES OPTIMIZATION.  SOURCE STORAGE REPRESENTATION IS NOT
PART OF THE ASSEMBLY LANGUAGE; NORMAL BUILDS OMIT -@A/-@S AND LET DAS SELECT
THE READER FROM THE INPUT FILE.

## SOURCE FORM

SOURCE IS LINE ORIENTED.  LABELS MAY PREFIX INSTRUCTIONS OR DIRECTIVES.
SEMICOLON STARTS A LINE COMMENT.  GAS STYLE BLOCK COMMENTS ARE ALSO ACCEPTED:

    /* COMMENT */

COMMENT MARKERS INSIDE QUOTED TEXT ARE NOT INTERPRETED AS COMMENTS.

INTEGER EXPRESSIONS ARE DECIMAL BY DEFAULT.  A LEGACY LEADING ZERO SELECTS
OCTAL.  0O, 0X, 0B, AND 0D SELECT OCTAL, HEXADECIMAL, BINARY, AND DECIMAL
EXPLICITLY.  NORMAL ARITHMETIC AND SYMBOL DIFFERENCE EXPRESSIONS ARE ACCEPTED
WHERE THEIR RELOCATION FORM IS REPRESENTABLE.

## SECTIONS

THE PRINCIPAL SECTIONS ARE:

    .TEXT
    .DATA
    .BSS

COMPATIBLE SECTION ALIASES USED BY PDP-10 TOOLCHAINS ARE ACCEPTED.  .PSECT IS
ALSO RECOGNIZED WHERE THE REQUEST CAN BE MAPPED TO THE DAS SECTION MODEL.

.ENTRY SELECTS THE PROGRAM ENTRY SYMBOL.  .ORG AND .ALIGN CONTROL LOCATION
PLACEMENT.  .BLOCK AND .SPACE RESERVE WORDS.

## SYMBOLS

.GLOBAL AND .GLOBL EXPORT A SYMBOL.  .EXTERN DECLARES AN EXTERNAL SYMBOL.
.COMM AND .LCOMM DEFINE COMMON STORAGE WITH GLOBAL AND LOCAL VISIBILITY.
.EQU DEFINES A FIXED SYMBOL VALUE.  .SET DEFINES AN ASSIGNABLE SYMBOL VALUE.

.IFDEF AND .IFNDEF USE SOURCE ORDER VISIBILITY.  A DEFINITION LATER IN THE
SOURCE DOES NOT MAKE A SYMBOL VISIBLE EARLIER IN THE FILE.

## INSTRUCTIONS

DAS ACCEPTS PDP-6 AND PDP-10 MEMORY REFERENCE INSTRUCTIONS, THE SUPPORTED I/O
INSTRUCTION SET, AND GENERIC UUO OPCODE,EA SYNTAX.  EFFECTIVE ADDRESSES MAY USE
INDIRECTION AND INDEX REGISTERS IN THE NORMAL PDP-10 FORM.

-@B REJECTS INSTRUCTIONS OUTSIDE THE STRICT BASE PROFILE.  -@K USES THE SAME
BASE RESTRICTIONS BUT PERMITS THE PRIVILEGED I/O INSTRUCTIONS REQUIRED BY THE
DAIMOS KERNEL AND STANDALONE PROGRAMS.

## DATA DIRECTIVES

THE MAIN DATA FORMS ARE:

    .WORD EXPR
    .LONG LEFT,RIGHT
    EXP EXPR
    POINT SIZE,ADDR,POS
    GIW ADDR
    OWGBP SELECTOR,ADDR
    .BYTE SIZE,VALUE,...
    .ASCII /TEXT/
    .ASCIZ /TEXT/
    SIXBIT /TEXT/
    .SIXBIT /TEXT/

SIXBIT PACKS SIX SIXBIT CHARACTERS PER WORD.  .ASCII AND .ASCIZ PACK 7 BIT
CHARACTERS, FIVE PER WORD.  .ASCIZ APPENDS A ZERO BYTE.

## INCLUDES

.INCLUDE READS ANOTHER SOURCE FILE:

    .INCLUDE "FILE.S"

RELATIVE INCLUDE PATHS ARE RESOLVED FROM THE INCLUDING FILE.  INCLUDES MAY BE
USED FROM REPEATED AND ITERATED BODIES.

## CONDITIONAL ASSEMBLY

DAS IMPLEMENTS:

    .IF EXPR
    .IFDEF SYMBOL
    .IFNDEF SYMBOL
    .ELSE
    .ENDIF

A CONDITIONAL MAY NOT CROSS A MACRO OR REPETITION EXPANSION BOUNDARY.

## MACROS

.MACRO AND .ENDM DEFINE GAS STYLE MACROS.  DAS SUPPORTS AT MOST NINE MACRO
ARGUMENTS AND AT MOST EIGHT ACTIVE MACRO INVOCATIONS.  DIRECT AND INDIRECT
MACRO RECURSION ARE REJECTED.

MACRO SUBSTITUTION SUPPORTS NAMED PARAMETERS, POSITIONAL \1 THROUGH \9, \@,
\(), AND ESCAPED BACKSLASH.  NESTED MACRO DEFINITIONS ARE NOT SUPPORTED.

## REPETITION

.REPT REPEATS A BODY A FIXED NUMBER OF TIMES:

    .REPT 3
    .WORD 1
    .ENDR

THE COUNT MUST BE ABSOLUTE AND BETWEEN 0 AND 65535.

.IRP ITERATES A SYMBOL OVER A COMMA SEPARATED LIST.  THE CURRENT VALUE IS
SUBSTITUTED FOR A BACKSLASH FOLLOWED BY THE ITERATOR NAME:

    .IRP R,1,2,3
    MOVEI \R,0
    .ENDR

AN .IRP WITH NO VALUE LIST EXPANDS ONCE WITH AN EMPTY VALUE.

.IRPC ITERATES A SYMBOL OVER THE CHARACTERS OF ITS VALUE TEXT:

    .IRPC C,"ABC"
    .SIXBIT /\C/
    .ENDR

DOUBLE QUOTES GROUP VALUE TEXT BUT ARE NOT ITERATED.  OTHER CHARACTERS,
INCLUDING COMMAS INSIDE THE VALUE TEXT, ARE ITERATED AS CHARACTERS.  AN .IRPC
WITH NO VALUE TEXT EXPANDS ONCE WITH AN EMPTY VALUE.

.REPT, .IRP, AND .IRPC SHARE AN EIGHT LEVEL ACTIVE REPETITION LIMIT.  NESTED
ITERATORS MAY SHADOW AN OUTER ITERATOR NAME.  THE OUTER VALUE RESUMES AFTER
THE INNER .ENDR.

## RELOCATION AND OUTPUT

DAS WRITES DXR BY DEFAULT.  DXR USES THE DAIMOS LOAD IMAGE AND RELOCATION
BITMAP MODEL.  RELOCATABLE EFFECTIVE ADDRESSES AND REPRESENTABLE HALF WORD
DATA RELOCATIONS ARE CHECKED RATHER THAN SILENTLY TRUNCATED.

THE -@C OPTION WRITES DOBJ1 RELOCATABLE OBJECTS IN BUILDS THAT INCLUDE THE DOBJ
PATH.  DOBJ PRESERVES TEXT, DATA, AND BSS SECTION IDENTITY, GLOBAL DEFINITIONS,
IMPORTS, AND RH18 OR LH18 RELOCATION RECORDS.  -@C AND -@F MAY BE USED
TOGETHER.

## OPTIMIZATION

-@F ENABLES THE BOUNDED PEEPHOLE AND FOLDING OPTIMIZER.
THE OPTIMIZER INCLUDES LOCAL VALUE, MOVE, IMMEDIATE, HALF WORD, ZERO, STORE
FORWARDING, AND RELATED FOLDS.  IT ALSO REMOVES AN UNNEEDED JRST TO THE NEXT
LABEL WHEN SAFE.

A CONDITIONAL JUMP FOLLOWED BY AN UNCONDITIONAL JRST TO A SECOND LABEL MAY BE
INVERTED WHEN THE FIRST TARGET IS THE IMMEDIATELY FOLLOWING LABEL:

    JUMPN 1,L1
    JRST L2
    L1:

MAY BECOME:

    JUMPE 1,L2
    L1:

DOBJ OPTIMIZATION UPDATES OR PRESERVES RELOCATION RECORDS AS REQUIRED.

DAS DOES NOT GENERALLY REPLACE ADDI OR SUBI FOLLOWED BY JUMP WITH AOJ OR SOJ.
THE PDP-6 ARITHMETIC FLAG SEMANTICS ARE NOT IDENTICAL IN ALL CASES.

## DIAGNOSTICS

DAS REJECTS MALFORMED EXPRESSIONS, UNSUPPORTED RELOCATION FORMS, UNDEFINED
LOCAL SYMBOLS, INVALID BASE PROFILE INSTRUCTIONS, UNMATCHED CONDITIONAL OR
REPETITION DIRECTIVES, MACRO RECURSION, EXCESSIVE EXPANSION DEPTH, AND SOURCE
LINES THAT EXCEED IMPLEMENTATION LIMITS.

AN ERROR PREVENTS A SUCCESSFUL OUTPUT IMAGE OR OBJECT.  THE DAIMOS-RESIDENT
PHASE IMAGES USE COMPACT DIAGNOSTICS TO REDUCE RESIDENT CODE AND DATA; BUILDS
WITH A FULL DIAGNOSTIC RUNTIME PRINT THE DETAILED FORM.

## EXAMPLES

ASSEMBLE AN OPTIMIZED KERNEL IMAGE:

    DAS -@K -@F -@O KERNEL.DXR KERNEL.S

ASSEMBLE AN OPTIMIZED DOBJ OBJECT:

    DAS -@C -@F -@O FILE.DOBJ FILE.S

ASSEMBLE A STRICT BASE DXR IMAGE WITH AUTOMATIC SOURCE-FORMAT DETECTION:

    DAS -@B -@O TEST.DXR TEST.S

## @?OPTIONS

### @?-O FILE - WRITE OUTPUT FILE

SELECT THE OUTPUT PATH.  -@O ALWAYS MEANS OUTPUT; OPTIMIZATION IS SELECTED
SEPARATELY WITH -@F.

### @?-F - ENABLE OPTIMIZATION

ENABLE THE BOUNDED DAS PEEPHOLE AND FOLDING OPTIMIZER.

### @?-B - USE STRICT BASE INSTRUCTION PROFILE

REJECT INSTRUCTIONS OUTSIDE THE BASE PDP-6 AND KA10 PROFILE.

### @?-K - USE BASE KERNEL INSTRUCTION PROFILE

USE THE STRICT BASE PROFILE WHILE PERMITTING THE PRIVILEGED I/O INSTRUCTIONS
REQUIRED BY DAIMOS KERNEL AND STANDALONE CODE.

### @?-S - SELECT S6REC SOURCE INPUT

FORCE S6REC INPUT.  NORMAL BUILDS USE AUTOMATIC DETECTION; S6REC REMAINS THE
NATIVE DAIMOS TEXT REPRESENTATION.

## @?OPERANDS

### @?SOURCE FILE

SOURCE ASSEMBLY FILE.  USE -@S FOR S6REC OR -@A FOR ORDINARY ASCII WHEN
THAT INPUT FORM IS AVAILABLE.

## @?EXIT STATUS

### @?0 - SUCCESS

THE SOURCE WAS ASSEMBLED SUCCESSFULLY.

### @?1 - ASSEMBLY FAILED

THE COMMAND LINE, INPUT, EXPANSION, ASSEMBLY, RELOCATION, OR OUTPUT OPERATION
FAILED.

## @?SEE ALSO

### @?DLINK

LINK DOBJ RELOCATABLE OBJECTS.

### @?DXRCHECK

VALIDATE AND INSPECT DXR IMAGES.

### @?S6FILTER

CONVERT ASCII TOOLING SOURCE TO DAIMOS S6REC TEXT.
