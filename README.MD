THIS REPOSITORY IS THE DOCUMENTATION HOME FOR THE SIBLING PDP-10/DAIMOS
REPOSITORIES. SOURCE TREES REMAIN THE AUTHORITY FOR IMPLEMENTED BEHAVIOR:

- '../DAIMOS'
- '../PDP10-TOOLS'
- '../GCC-3.2-PDP10'
- '../KCC-LINUX'
- '../PDP10-C-TESTKIT'

## LAYOUT

- 'BOOT/' - DAIMOS PDP-6 BOOT, DBOOT, BOOTINFO, STAGE1, AND RESCUE NOTES.
- 'KERNEL/' - DAIMON/KRES/KINIT, DSK270, D6FS, DECTAPE FS, MODULES, AND OBJECT-WORK NOTES.
- 'STATUS/' - SIZE REPORTS AND SHORT DATED STATUS NOTES.
- 'TOOLCHAIN/' - GCC/KCC PLANS AND TESTKIT NOTES.
- 'TOOLS/' - DAS, DXR, DOBJ, ASSEMBLER, AND HELPER-TOOL NOTES.
- 'USER/' - DSH, DEX0R, RUN/WAIT, AND EARLY USERLAND ABI NOTES.
- 'REFS/' - OCR/MANUAL EXCERPTS AND EXTRACTED REFERENCE FIGURES. THIS FOLDER IS REFERENCE MATERIAL AND IS NOT EDITED DURING CONSOLIDATION PASSES.

ROOT-LEVEL REPOSITORY WORK LIVES IN 'TODO.MD'. ROOT-LEVEL DOCUMENTS SHOULD STAY
LIMITED TO REPOSITORY OVERVIEW AND REPOSITORY-WIDE TODOS.

FOR ACTIVE IMPLEMENTATION STATE, CHECK THE SOURCE TREES FIRST. THE DOCS HERE
RECORD DESIGN DECISIONS, STABLE FORMATS, AND STATUS NOTES THAT ARE STILL USEFUL
OUTSIDE THE SOURCE.
