# PDP-10 AND DAIMOS DOCUMENTATION

THIS REPOSITORY HOLDS CURRENT DESIGN DOCUMENTATION FOR DAIMOS AND THE SIBLING
PDP-10 TOOLCHAIN/UTILITY TREES.  SOURCE TREES REMAIN AUTHORITATIVE FOR WHAT IS
ACTUALLY IMPLEMENTED; DAIMOS/PROJECT-STATE.MD IS AUTHORITATIVE FOR CURRENT
DAIMOS ARCHITECTURAL STATE AND DEVELOPMENT ORDER.

## LAYOUT

- 'BOOT/' - PDP-6 BOOT, DBOOT, STAGE1, BOOTINFO, AND DEFERRED RECOVERY DESIGN.
- 'KERNEL/' - MEMORY/VM, STORAGE, FILESYSTEM, LOGSTORE, MODULE, AND SELF-HOSTING
  DESIGN.
- 'STATUS/' - CURRENT SCOPE/SIZE SUMMARIES AND USEFUL DATED IMPLEMENTATION
  HANDOFFS.
- 'TOOLCHAIN/' - GCC/KCC AND C/TESTKIT DESIGN NOTES.
- 'TOOLS/' - DAS, DOBJ, DISPLAY/CONVERSION, AND SUPPORT-TOOL DOCUMENTATION.
- 'USER/' - DSH, SIXMD, USER COMMAND, AND USERLAND DESIGN.

ROOT-LEVEL OPEN DOCUMENTATION WORK IS IN TODO.MD.  HISTORICAL MATERIAL THAT IS
NO LONGER PART OF THE ACTIVE DESIGN SHOULD BE RECOVERED FROM GIT HISTORY RATHER
THAN KEPT AS A CONTRADICTORY SECOND AUTHORITY.

## CURRENT DAIMOS BOUNDARIES

THE INITIAL/MINIMUM MACHINE IS A 32K-WORD PDP-6.  THE CURRENT SHRINK TARGET IS
A 14K TOTAL KERNEL FOOTPRINT, MEASURED AS KCC KCORE+MRES <= 14288 DECIMAL
WORDS AFTER ACCOUNTING FOR LOW CORE.  THE HARD ARCHITECTURAL LIMIT IS BELOW
16K WORDS INCLUDING ALL RESIDENT AND SCRATCH KERNEL MEMORY.

KCC IS THE REQUIRED NORMAL COMPILER FOR BOTH KERNEL AND USERSPACE.  CURRENT
USERSPACE CONVERSION FROM GCC/LIBGCC TO KCC IS THE IMMEDIATE BLOCKER BEFORE
FURTHER USERSPACE FEATURE WORK.

THE CURRENT DESIGN ALSO RECORDS TWO LATER KERNEL CONSOLIDATIONS:

- D6FS OWNS OPTIONAL SWAP/LOGSTORE LOGICAL RESERVATIONS; VFS REGISTERS THE RAW
  RANGES; DISKSET OWNS PHYSICAL DISTRIBUTION/SCHEDULING/BAD-MEDIA MAPPING.
- MONITORFS AT /MONITOR REPLACES PROCFS/DOMAINFS/DEVFS STATE VIEWS; /DEV IS AN
  I/O-ONLY ALTERNATE VIEW IMPLEMENTED BY THE SAME MONITORFS CODE.  THERE IS NO
  FUTURE /PROC FILESYSTEM.
