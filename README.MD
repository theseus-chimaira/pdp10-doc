# PDP-10 AND DAIMOS DOCUMENTATION

THIS REPOSITORY HOLDS CURRENT DESIGN DOCUMENTATION FOR DAIMOS AND THE SIBLING
PDP-10 TOOLCHAIN/UTILITY TREES.  SOURCE TREES REMAIN AUTHORITATIVE FOR WHAT IS
ACTUALLY IMPLEMENTED; DAIMOS/PROJECT-STATE.MD IS AUTHORITATIVE FOR CURRENT
DAIMOS ARCHITECTURAL STATE AND DEVELOPMENT ORDER.

## CURRENT DAIMOS BOUNDARIES

THE INITIAL/MINIMUM MACHINE IS A 32K-WORD PDP-6.  THE CURRENT 14K SHRINK GATE
IS KCC KCORE+MRES <= 14288 DECIMAL WORDS AFTER ACCOUNTING FOR LOW CORE.  THE
CURRENT FRESH MEASUREMENT IS 14266 KCORE+MRES WITH PERMANENT_LAST 033751; THE
SIZE GATE IS MET AND LOGIN/EXEC ACCEPTANCE STILL HAS TO CLOSE THE PASS.  THE
HARD ARCHITECTURAL LIMIT IS BELOW 16K WORDS INCLUDING ALL RESIDENT AND SCRATCH
KERNEL MEMORY.

KCC IS THE REQUIRED NORMAL COMPILER FOR BOTH KERNEL AND USERSPACE.  CURRENT
USERSPACE CONVERSION FROM GCC/LIBGCC TO KCC IS THE IMMEDIATE BLOCKER.  AFTER
THAT, COMPLETE THE PROGRAM-STARTUP ABI, MINIMAL TTY LINE DISCIPLINE, AND
RECLAIMABLE D6FS BLOCK CACHE BEFORE THE SUBSTANTIAL DSH PORT.  THE STANDARD
PETIT PCLK/GETTIME PATH IS ALREADY AN EARLY HARDWARE PREREQUISITE; AFTER DSH,
COMPLETE D6FS MTIME PLUMBING BEFORE MAKE.

THE CURRENT DESIGN ALSO RECORDS TWO LATER KERNEL CONSOLIDATIONS:

- D6FS OWNS OPTIONAL SWAP/LOGSTORE LOGICAL RESERVATIONS; VFS REGISTERS THE RAW
  RANGES; DISKSET OWNS PHYSICAL DISTRIBUTION/SCHEDULING/BAD-MEDIA MAPPING.
- MONITORFS AT /MONITOR REPLACES PROCFS/DOMAINFS/DEVFS STATE VIEWS; /DEV IS AN
  I/O-ONLY ALTERNATE VIEW IMPLEMENTED BY THE SAME MONITORFS CODE.  THERE IS NO
  FUTURE /PROC FILESYSTEM.
- D6FS USES AN ELASTIC RECLAIMABLE BLOCK CACHE BORROWING FREE MANAGED CORE;
  CLEAN CACHE IS RECLAIMED BEFORE PROCESS SWAP AND DOES NOT BECOME A LARGE
  FIXED RESIDENT BUFFER POOL.
- THE KERNEL PROVIDES ONLY A MINIMAL COOKED TTY LINE DISCIPLINE; DSH/ELVIS KEEP
  RICH INTERACTIVE EDITING IN USERSPACE AND USE RAW MODE WHEN NEEDED.
