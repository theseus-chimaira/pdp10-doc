# PDP-6 WCNSLS / COLOR-SCOPE INTERFACE

DATE: 2026-10-06
STATUS: IMPLEMENTED DAIMOS RUNTIME ABI

## 1. DEVICE MODEL

PDP-6 DEVICE 0420 COMBINES THE MIT SPACEWAR SWITCH BANKS WITH THE OPTIONAL
COLOR-SCOPE POINT PLOTTER.  IT IS NOT A TERMINAL AND SHALL NEVER BE ROUTED
THROUGH THE DAIMOS TTY OR LINE-DISCIPLINE LAYERS.

THE HARDWARE OPERATIONS USED BY DAIMOS ARE:

- `DATAI 0420` FOR THE FOUR ACTIVE-LOW SPACEWAR CONTROL BANKS;
- `CONO 0420` FOR SPACEWAR ENABLE AND THE RED/GREEN/BLUE INTENSITY LATCHES;
- `DATAO 0420` FOR COLOR-SCOPE POINT COORDINATES.

THE SCOPE HAS NO RETAINED DISPLAY LIST.  PHOSPHOR PERSISTENCE IS CREATED BY
REPEATED PLOTTING.  PICTURE STORAGE, FRAME GENERATION, REFRESH RATE, ANIMATION,
COLOR SEQUENCING, AND IMAGE CONVERSION THEREFORE BELONG TO USERSPACE.

## 2. PRIVILEGED USERSPACE ABI

WHEN WCNSLS PROBES SUCCESSFULLY, DAIMOS PUBLISHES `/DEV/WCNSLS`.  THE NORMAL
MONITORFS DEVICE MODE IS `0600`, SO OPENING THE RAW HARDWARE ENDPOINT REQUIRES
ROOT PRIVILEGE.  AFTER A SUCCESSFUL OPEN, THE FILE DESCRIPTOR IS THE ACCESS
CAPABILITY; THE REALTIME WRITE PATH DOES NOT RECHECK CREDENTIALS PER WORD.

`READ_WORDS` RETURNS ONE RAW `DATAI 0420` SAMPLE.  A REQUEST WITH NONZERO
CAPACITY MAY COMPLETE SHORT WITH ONE WORD, WHICH IS THE NORMAL DEVICE-stream
CONTRACT.

`WRITE_WORDS` EXECUTES A BATCH OF RAW DEVICE OPERATIONS.  EACH 36-BIT WORD IS:

    BIT 35 CLEAR   DATAO 0420 USING THE REMAINING WORD UNCHANGED
    BIT 35 SET     CONO  0420 USING THE LOW 18-BIT CONTROL WORD

THE TAG VALUE IS `0400000000000`.  THE KERNEL DOES NOT DEFINE COLOR, POINT,
FRAME, OR PICTURE RECORDS ABOVE THESE OPERATIONS.  USERSPACE MAY ISSUE MANY
DATAO POINTS BETWEEN CONO COLOR CHANGES IN ONE WRITE TO AVOID ONE MONITOR
TRANSITION PER POINT.

REALTIME SCHEDULING AND DEVICE PRIVILEGE ARE ORTHOGONAL.  A PRIVILEGED PROGRAM
MAY OPEN `/DEV/WCNSLS` AND THEN USE RTCTL FOR LOW-JITTER REFRESH, BUT RTCTL
DOES NOT ITSELF GRANT WCNSLS ACCESS.

## 3. KERNEL IMPLEMENTATION

KINIT RETAINS ITS OWN DISPOSABLE SINGLE-OPERATION WCNSLS PRIMITIVES FOR PROBE
AND THE BOOT BANNER.  AFTER PROBE IT INSTALLS A 22-WORD MRES CONTAINING ONLY:

- `wcnsls_read_words`;
- `wcnsls_write_words`.

THE MRES HAS NO BSS, INTERRUPT HANDLER, FRAMEBUFFER, RETAINED DISPLAY PROGRAM,
REFRESH TIMER, TTY STATE, OR GRAPHICS OBJECT MODEL.  THE FILE LAYER PATCHES TWO
SERVICE JUMPS TO THE INSTALLED PACKAGE and dispatches `/DEV/WCNSLS` bulk word
I/O directly to them.

MONITORFS COUNTS ONE COMPLETED READ REQUEST FOR A SUCCESSFUL DATAI READ AND ONE
COMPLETED WRITE REQUEST FOR A SUCCESSFUL BATCH, NOT ONE EVENT PER POINT.

## 4. COLOR REGISTER LAYOUT

THE IMPLEMENTED DEVICE-0420 COLOR CONTROL LAYOUT IS:

    BLUE  ENABLE 0000020   INTENSITY 0000017
    GREEN ENABLE 0002000   INTENSITY 0001700
    RED   ENABLE 0200000   INTENSITY 0170000

SPACEWAR INPUT ENABLE IS `0000040`.

SIMH AND THE AAP PDP-6 EMULATOR MUST IMPLEMENT THIS SAME LAYOUT.  THE AAP
EMULATOR PREVIOUSLY USED GREEN/RED ENABLE CONSTANTS ONE OCTAL DIGIT TOO HIGH
WHILE EXTRACTING THE INTENSITY FIELDS AT THE CORRECT SHIFTS; THAT EMULATOR BUG
WAS CORRECTED RATHER THAN WORKED AROUND IN DAIMOS.

## 5. VALIDATION

`daimos-testkit` TARGET `test-daimos-wcnsls-raw` BOOTS A REAL PDP-6 DAIMOS
IMAGE, OPENS `/DEV/WCNSLS` AS ROOT, ENABLES REALTIME SCHEDULING, SUBMITS A
BATCH CONTAINING RED/GREEN CONO CHANGES AND TWO DATAO POINTS, PERFORMS RAW
DATAI, AND CHECKS THE SIMH DEVICE TRACE FOR THE EXACT OPERATIONS.
