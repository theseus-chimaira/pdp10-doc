# AAP PDP-6 EMULATOR INTEGRATION

DATE: 2026-10-01
STATUS: VERIFIED BUILD/INSTALL CONTRACT

## 1. PURPOSE

THE AAP PDP-6 EMULATOR IN `~/git/pdp6` IS AN INDEPENDENT PDP-6 IMPLEMENTATION
BASED CLOSELY ON THE ORIGINAL MACHINE SCHEMATICS.  IT IS A USEFUL SECOND
DAIMOS EXECUTION TARGET BECAUSE IT EXERCISES PDP-6 CPU, PI, RELOCATION,
TYPE-136 DATA-CONTROL, AND TYPE-551/555 DECTAPE BEHAVIOR INDEPENDENTLY OF SIMH.

THE VERIFIED DAIMOS-CAPABLE HARDWARE SET IS:

- PDP-6 APR 166 WITH USER MODE, RELOCATION/PROTECTION, PI, APR CONDITIONS, AND
  THE 60 HZ LINE CLOCK;
- TYPE-162 FAST MEMORY AND CORE/MOBY MEMORY;
- TYPE-626 CONSOLE TTY AT 0120;
- TYPE-760 PAPER-TAPE READER AT 0104;
- TYPE-761 PAPER-TAPE PUNCH AT 0100;
- TYPE-136 DATA CONTROL AT 0200;
- TYPE-551 DECTAPE CONTROL AT 0210/0214 WITH UP TO EIGHT TYPE-555 TRANSPORTS;
- STANFORD PHIL PETIT PCLK AT 0730, ADDED FOR THE DAIMOS WALL-CLOCK CONTRACT;
- TYPE-340 DISPLAY AT 0130;
- SPACEWAR/COLOR-SCOPE INTERFACE AT 0420;
- SECOND SPACEWAR CONSOLE INPUT INTERFACE AT 0724.

NETWORK MEMORY AND NETWORK CONSOLE DEVICES ARE EMULATOR HOST INTEGRATION
FACILITIES, NOT PDP-6 HARDWARE, AND ARE NOT PART OF THE FULL-HARDWARE DAIMOS
PROFILES.

## 2. DECTAPE PROFILES

TWO INSTALLED CONFIGURATIONS ARE MAINTAINED:

    /usr/local/share/pdp6-aap-v1/init-full-4dt-v1.ini
    /usr/local/share/pdp6-aap-v1/init-full-8dt-v1.ini

THE FIRST CONNECTS FOUR TYPE-555 TRANSPORTS TO ONE TYPE-551 CONTROL.  THE
SECOND CONNECTS ALL EIGHT SUPPORTED TRANSPORTS.  BOTH ENABLE EVERY OTHER
EMULATED PDP-6 HARDWARE DEVICE LISTED ABOVE.  MEDIA AND TTY PATHS ARE LEFT
UNMOUNTED SO THE INSTALLED CONFIGURATIONS REMAIN HOST-INDEPENDENT.

DAIMOS CAN USE THE DTC/TSFS ROOT PATH ON THIS EMULATOR WITHOUT TYPE-270 DISK OR
TYPE-236 DRUM HARDWARE.  THE REPOSITORY TOOL `DTA2DTR` CONVERTS SIMH `.DTA`
DECTAPE IMAGES TO THE RAW `.DTR` REPRESENTATION USED BY THIS EMULATOR.

## 3. PCLK

DAIMOS REQUIRES THE PETIT CLOCK AS ITS STANDARD CIVIL UTC SOURCE.  THE AAP
EMULATOR NOW IMPLEMENTS DEVICE 0730 AS `PCLK730`.  IT REPORTS HOST UTC USING
THE HISTORICAL PETIT DATAI/CONI REGISTER ENCODING.  THE APR 60 HZ LINE CLOCK
REMAINS INDEPENDENT AND CONTINUES TO DRIVE SCHEDULING, SLEEP, AND TIMEOUTS.

PCLK INTERRUPT DELIVERY IS NOT IMPLEMENTED OR REQUIRED.  DAIMOS READS THE
PCLK ON DEMAND.

## 4. SECOND SPACEWAR INTERFACE

THE 0724 DEVICE IS NOT AN ALIAS OF THE 0420 SPACEWAR/COLOR-SCOPE DEVICE.  THE
UPSTREAM EMULATOR HISTORY INTRODUCED IT IN COMMIT `3F57389` WITH THE DESCRIPTION
"DEVICE 724 WITH TWO SPACEWAR CONSOLES."  ITS DATAI VALUE IS A SEPARATE 36-BIT
INPUT WORD USING AN 18-BIT FIELD PER CONTROLLER AND INCLUDES AXIS DIRECTION,
TORPEDO, HYPERSPACE, BEACON, TIMING, TRANSMIT, AND DESTRUCT-STYLE INPUTS.

DAIMOS SUPPORT FOR 0724 IS DEFERRED POST-0.9.  ITS DRIVER MUST REMAIN DISTINCT
FROM THE 0420 COLOR-SCOPE/SPACEWAR INTERFACE AND SHOULD FREEZE A GUEST ABI ONLY
AFTER THE HISTORICAL REGISTER SEMANTICS HAVE BEEN CONFIRMED.

## 5. INSTALLED NAMES

THE EMULATOR IS INSTALLED WITHOUT REPLACING THE SIMH PDP-6 BINARY:

    /usr/local/bin/pdp6                 EXISTING SIMH, UNCHANGED
    /usr/local/libexec/pdp6-aap-v1/pdp6-aap-v1
    /usr/local/bin/pdp6-aap-4dt-v1
    /usr/local/bin/pdp6-aap-8dt-v1

THE TWO FRONT-END SCRIPTS CREATE A PRIVATE WORKING DIRECTORY UNDER `$TMPDIR`
(OR `$HOME/tmp` WHEN TMPDIR IS UNSET), LINK THE SELECTED INSTALLED CONFIGURATION
AS `EMU/INIT.INI`, RUN THE EMULATOR, AND REMOVE THE PRIVATE DIRECTORY ON EXIT.
