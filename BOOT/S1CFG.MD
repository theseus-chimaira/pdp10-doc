# DAIMON STAGE1 BOOT CONFIGURATION V1

STATUS: PLANNED S1CFG/BOOTCFG DESIGN NOTE, NOT THE CURRENT STAGE1 DEFAULT
SCOPE: PDP-6 FIRST, WITH RESERVED DEVICE IDS FOR KA10/KI10-CLASS SIMH STORAGE
DATE: 2026-06-22

CURRENT V0.9 NOTE (2026-09-26): THIS REMAINS A POST-0.9/PERSISTENT-POLICY
DESIGN.  CURRENT ROOT SELECTION IS NOT CARRIED IN S1CFG OR AN EXTRA BOOTINFO
WORD.  KINIT READS A FIVE-BIT CONSOLE-SWITCH FIELD: LOW THREE BITS SELECT
AUTO/DSK/DTC/DRM/RAM-RESERVED AND THE NEXT TWO BITS SELECT THE FIRST THROUGH
FOURTH DISTINCT DISCOVERED ROOT SET.  BOOT TRANSPORT REMAINS INDEPENDENT OF
ROOT FILESYSTEM.  CURRENT DSK/D6FS, DTC/TSFS, AND DRM/D6FS ROOTS ALL BOOT
THROUGH INIT TO LOGIN.  DRM AS A BOOT TRANSPORT REMAINS A SEPARATE FUTURE
STAGE1 ITEM AND IS NOT REQUIRED TO USE DRM/D6FS AS `/`.

THIS DOCUMENT ADDS A SMALL PERSISTENT BOOT CONFIGURATION LAYER TO THE EXISTING
DBOOT/BOOTINFO DESIGN.  IT DOES NOT REPLACE DBOOT.  THE LIVE SOURCE CONTRACT IS
'../DAIMOS/INCLUDE/S1CFG_V1.H'; THE CURRENT DEFAULT HDD BOOT PATH CARRIES KICFG
INSIDE DBX/DBC AND DOES NOT REQUIRE AN S1CFG SECTOR.

THE PLANNED BOOT CONFIGURATION SELECTS POLICY: BOOT MODE, DEFAULT BOOT DEVICE,
CONSOLE ROUTING, KERNEL/ROOT SELECTION, AND THE MODULE POLICY LATER CONSUMED BY
KINIT.

ALL IDENTIFIERS STORED ON MEDIA ARE NUMERIC OR SIXBIT.  STAGE1 MUST NOT PARSE
TEXT STRINGS FROM DISK OR DECTAPE.

## 1. GOALS

THE BOOT PATH NEEDS THESE CAPABILITIES:

- NORMAL VS SINGLE-USER BOOT
- DEFAULT BOOT DEVICE OR BOOT SET SELECTION
- OPERATOR-PROMPT POLICY
- CONSOLE OUTPUT POLICY
- KERNEL/PROFILE FALLBACK POLICY
- ROOT SELECTION POLICY
- MODULE INCLUDE/EXCLUDE/DISABLE POLICY
- DIAGNOSTIC VERBOSITY AND SAFE-MODE FLAGS
- ENOUGH INFORMATION FOR KINIT TO CONTINUE WITH THE SAME BOOT INTENT

THE NORMAL STAGE1 LOADER MUST STAY SMALL.  THEREFORE STAGE1 PARSES ONLY A COMPACT
FIXED RECORD.  KINIT MAY PARSE THE FULL RECORD SET AFTER IT HAS MORE MEMORY AND
BETTER DIAGNOSTICS.

SINGLE-USER FLAGS IN THIS PLANNED FORMAT ARE RESERVED FOR POST-0.9 RECOVERY/
ADMINISTRATIVE WORK.  DAIMOS 0.9 DOES NOT REQUIRE A WORKING SINGLE-USER OR
RECOVERY ENVIRONMENT; DO NOT MAKE THESE FLAGS A CURRENT IMPLEMENTATION GATE.

## 2. STORAGE MODEL

THE FUTURE MEDIA DESCRIPTOR/PROFILE SHOULD RESERVE A CFGSTORE OBJECT OR REGION.
THAT STORAGE SHOULD HOLD REPLICATED BOOT CONFIGURATION SECTORS.

RECOMMENDED V1 PLACEMENT:

'''TEXT
DBOOT/DBX/DBC       MEDIA LAYOUT, GENERATION, BADMAP, REGION TABLE
CFGSTORE SECTOR 0   BCF COMPACT ACTIVE BOOT CONFIGURATION SECTOR
CFGSTORE SECTOR 1   BCF COMPACT PREVIOUS-GOOD SECTOR
CFGSTORE SECTOR 2   BCFX EXTENDED KINIT CONFIGURATION SECTOR, OPTIONAL
CFGSTORE SECTOR 3   RESERVED SPARE / NEXT GENERATION
'''

STAGE1 SCAN ORDER:

1. FIND AND VALIDATE DBOOT AS TODAY.
2. IF CFGSTORE IS PRESENT, READ THE ACTIVE BCF COMPACT SECTOR.
3. IF ACTIVE BCF IS INVALID, TRY PREVIOUS-GOOD BCF.
4. IF NO VALID BCF EXISTS, USE BUILT-IN SAFE DEFAULTS.
5. BUILD BOOTINFO WITH THE SELECTED BOOT FLAGS AND BOOTDEV WORD.

THE PAPER-TAPE CONFIGURATION PROGRAM AND THE OS USER PROGRAM BOTH WRITE THE SAME
BCF RECORDS.  THE NORMAL BOOT STAGE1 SHOULD NOT CONTAIN A FULL EDITOR.

S1CFG IS DELIBERATELY SMALL.  A FUTURE VERSION MAY USE IT TO CHOOSE POLICY AND
MODULE IDS, BUT THE CURRENT STAGE1 PATH DOES NOT CONSUME IT.  CURRENT HDD BOOT
USES DBX/DBC KICFG WORDS PLUS THE DMANIF MANIFEST EMBEDDED IN THE INIT STREAM.
STAGE1 LOADS THAT INIT STREAM AS OPAQUE DATA; KINIT CONSUMES THE POLICY AND
MANIFEST.

## 3. SHARED PROGRAMS

THERE SHOULD BE TWO FRONT ENDS BUILT FROM THE SAME SOURCE TREE:

'''TEXT
STANDALONE BOOTCFG TAPE
  BOOTABLE PAPER TAPE
  USES STANDALONE RAW DSK270 FIRST, LATER DTC/DT DRIVERS
  READS DBOOT/CFGSTORE DIRECTLY
  WRITES BCF REPLICAS AFTER OPERATOR CONFIRMATION

OS BOOTCFG PROGRAM
  DAIMOS USER PROGRAM
  USES /DEV/RAW STYLE BLOCK DEVICES
  SAME PARSER, VALIDATOR, CHECKSUM, AND RECORD WRITER
  CAN SHOW AND EDIT THE FULL KINIT-VISIBLE CONFIGURATION
'''

SHARED C CORE:

'''TEXT
BOOTCFG_CORE.C       FIXED-RECORD PARSER/WRITER/CHECKSUM/VALIDATION
BOOTCFG_DEVICES.C    ABSTRACT MEDIA PROBE/READ/WRITE CALLBACKS
BOOTCFG_CMD.C        SMALL COMMAND INTERPRETER, REUSED BY BOTH FRONT ENDS
BOOTCFG_SIXBIT.C     SIXBIT HELPERS, NO LOCALE, NO DYNAMIC ALLOCATION
'''

THE STANDALONE TAPE LINKS THE SHARED C CORE WITH TINY ASSEMBLY/C DRIVERS.  THE
OS TOOL LINKS THE SAME CORE AGAINST DAIMOS FILE AND BLOCK-DEVICE CALLS.  THE
SHARED CORE MUST BE FREESTANDING-FRIENDLY AND BOUNDED: NO MALLOC, NO STDIO IN
THE CORE, NO UNBOUNDED MODULE LIST.

## 4. COMPACT BCF SECTOR

A COMPACT BCF SECTOR IS ONE 128-WORD SECTOR.  IT IS THE ONLY CONFIGURATION RECORD
STAGE1 V1 MUST UNDERSTAND.

COMMON HEADER SHAPE MATCHES THE EXISTING DBOOT COMMON HEADER STYLE:

'''TEXT
BITS 35..18  MAGIC, THREE SIXBIT CHARACTERS, BCF
BITS 17..12  VERSION, V1 = 1
BITS 11..5   COUNT, TOTAL BCF WORDS USED
BITS 4..0    FLAGS
'''

BCF V1 FIXED WORDS:

'''TEXT
WORD 000  HEADER, MAGIC BCF
WORD 001  TOTAL WORDS, V1 COMPACT = 0100 OR LESS
WORD 002  CHECKSUM OVER USED WORDS WITH THIS WORD ZEROED
WORD 003  CONFIG GENERATION
WORD 004  TARGET BOOT SET UUID0, ZERO MEANS ANY
WORD 005  TARGET BOOT SET UUID1, ZERO MEANS ANY
WORD 006  TARGET BOOT SET UUID2, ZERO MEANS ANY
WORD 007  BOOT FLAGS
WORD 010  DEFAULT BOOT DEVICE WORD
WORD 011  FALLBACK BOOT DEVICE WORD, ZERO MEANS NONE
WORD 012  CONSOLE POLICY WORD
WORD 013  KERNEL/ROOT POLICY WORD
WORD 014  MODULE POLICY WORD
WORD 015  SCAN POLICY WORD
WORD 016  OPERATOR PROMPT WORD
WORD 017  RESERVED, MUST BE ZERO IN V1
WORD 020  FIRST COMPACT MODULE RULE
...
'''

BCF FLAGS:

'''TEXT
000001  CHECKSUM PRESENT
000002  ACTIVE RECORD
000004  PREVIOUS-GOOD RECORD
000010  HAS EXTENDED BCFX RECORD
000020  RECORD WAS WRITTEN BY STANDALONE TAPE
'''

STAGE1 ACCEPTS A BCF ONLY WHEN:

- MAGIC, VERSION, COUNT, AND CHECKSUM ARE VALID
- RESERVED CHECKED FIELDS ARE ZERO
- THE TARGET UUID IS ZERO OR MATCHES THE SELECTED BOOT SET
- THE BOOT DEVICE CLASS IS SUPPORTED BY THIS STAGE1 BUILD

## 5. BOOT FLAGS

THE BOOT FLAGS WORD IS PASSED THROUGH BOOTINFO FOR KINIT.

'''TEXT
000000000001  SINGLE-USER BOOT
000000000002  ASK FOR ROOT/INIT BEFORE MULTI-USER
000000000004  SAFE MODE: NO OPTIONAL MODULES
000000000010  DISABLE AUTOMATIC MODULE DISCOVERY
000000000020  FORCE VERBOSE STAGE1 DIAGNOSTICS
000000000040  FORCE VERBOSE KINIT DIAGNOSTICS
000000000100  MOUNT ROOT READ-ONLY FIRST
000000000200  SKIP NONESSENTIAL FSCK/REPAIR AT BOOT
000000001000  PREFER PREVIOUS-GOOD KERNEL/PROFILE
000000002000  HALT AFTER STAGE1 DIAGNOSTICS BEFORE KINIT
000000004000  IGNORE SAVED CONSOLE SWITCH, USE CTY ONLY
000000010000  ALLOW DEGRADED BOOT SET IF DESCRIPTOR PERMITS IT
'''

STAGE1 SHOULD ACT ONLY ON FLAGS THAT AFFECT STAGE1 ITSELF: VERBOSE DIAGNOSTICS,
HALT-BEFORE-KINIT, DEFAULT DEVICE SELECTION, AND OPERATOR PROMPT.  KINIT OWNS THE
REST.

## 6. BOOT DEVICE WORD

THE BOOT DEVICE WORD IS A MACHINE-NEUTRAL ENCODED DEVICE SELECTOR.  IT IDENTIFIES
PHYSICAL BOOT MEDIA WITHOUT STORING TEXT NAMES.

'''TEXT
BITS 35..30  BOOT DEVICE CLASS
BITS 29..24  CONTROLLER INDEX
BITS 23..18  UNIT NUMBER
BITS 17..12  ATTACHMENT/CHANNEL INDEX
BITS 11..6   DRIVE SUBTYPE HINT, ZERO MEANS UNKNOWN/DEFAULT
BITS 5..0    FLAGS
'''

DEVICE CLASSES:

'''TEXT
00  NONE / USE SCAN ORDER
01  PDP-6 DSK270 DISK CONTROLLER, SIMH DSK
02  PDP-6 551 DECTAPE CONTROLLER, SIMH DTC
03  KA/KI TD10/TU55 DECTAPE, SIMH DT
04  RP10 RP01/RP02/RP03 DISK PACK, SIMH DP[A-D]
05  RC10 RD10/RM10 FIXED-HEAD/DRUM, SIMH FH[A-B]
06  RH10/RH20 RP04/RP05/RP06/RP07 MASSBUS DISK, SIMH RP[A-D]
07  RH10/RH20 RS03/RS04 FIXED-HEAD DISK, SIMH FS[A-D]
'''

FLAGS:

'''TEXT
000001  BOOT ONLY FROM THIS EXACT DEVICE
000002  PREFER THIS DEVICE, BUT ALLOW SCAN FALLBACK
000004  DEVICE IS REMOVABLE
000010  DEVICE BELONGS TO A MULTI-MEMBER BOOT SET
'''

SUBTYPE HINTS ARE ADVISORY.  STAGE1 MUST VALIDATE THE DBOOT DESCRIPTOR ON THE
MEDIA INSTEAD OF TRUSTING THE SUBTYPE.

## 7. CONSOLE POLICY

STAGE1 SHOULD ALWAYS KEEP CTY AVAILABLE.  OTHER CONSOLE OUTPUT IS A MIRROR OR A
KINIT SWITCH, NOT A REPLACEMENT DURING EARLY STAGE1.

CONSOLE POLICY WORD:

'''TEXT
BITS 35..30  PRIMARY CONSOLE CLASS
BITS 29..24  MIRROR CONSOLE CLASS
BITS 23..18  LINE/UNIT
BITS 17..12  HANDOFF CLASS FOR KINIT
BITS 11..0   FLAGS
'''

CONSOLE CLASSES:

'''TEXT
00  CTY
01  DCS LINE
02  DC LINE
03  GRAPHICS CONSOLE MIRROR, IF A SUITABLE MODULE/DRIVER EXISTS LATER
'''

FLAGS:

'''TEXT
000001  MIRROR STAGE1 OUTPUT WHEN DRIVER IS COMPILED IN
000002  KINIT MAY SWITCH PRIMARY CONSOLE AFTER KEYBOARD ROUTING IS READY
000004  SUPPRESS NONFATAL STAGE1 PROGRESS LINES
000010  REQUIRE OPERATOR CONFIRMATION BEFORE CONSOLE SWITCH
'''

FOR V1 PDP-6 BOOT THIS EFFECTIVELY MEANS CTY-ONLY OR CTY PLUS A LATER MIRROR.
A GRAPHICS CONSOLE CANNOT SAFELY BECOME THE ONLY CONSOLE DURING STAGE1 BECAUSE
INPUT STILL COMES FROM THE CONSOLE KEYBOARD UNLESS A SEPARATE KEYBOARD DEVICE IS
IMPLEMENTED.

## 8. KERNEL, ROOT, AND MODULE POLICIES

KERNEL/ROOT POLICY WORD:

'''TEXT
BITS 35..30  KERNEL PROFILE NUMBER, ZERO = DESCRIPTOR DEFAULT
BITS 29..24  PREVIOUS-GOOD FALLBACK PROFILE, ZERO = NONE
BITS 23..18  ROOT POLICY
BITS 17..12  INIT POLICY
BITS 11..0   FLAGS
'''

ROOT POLICIES:

'''TEXT
00  DESCRIPTOR DEFAULT
01  RESERVED (OLD INITFS0 TEST ROOT; DO NOT USE)
02  FSREGION ON SELECTED BOOT SET
03  DECTAPE ROOT AFTER NON-DECTAPE BOOT, IF LATER NEEDED
04  ASK OPERATOR
'''

POST-0.9 RECOVERY IS PLANNED AS A BOOTABLE RECOVERY DECTAPE ENVIRONMENT USING
THE NORMAL MAINTENANCE TOOLS.  IT DOES NOT REINTRODUCE INITFS0 AS AN EMERGENCY
ROOT.  THE DEDICATED DECTAPE BOOT PATH MAY USE ITS OWN RECOVERY POLICY RATHER
THAN THIS DISK-STAGE1 ROOT SELECTOR.

MODULE POLICY WORD:

'''TEXT
BITS 35..30  GLOBAL MODULE MODE
BITS 29..0   RESERVED, MUST BE ZERO IN V1
'''

THE PLANNED STARTUP MODULE BITMAP LIVES IN FIXED S1CFG WORDS 012..015.  EXTRA
MODULE-SPECIFIC OPTIONS USE THE COMPACT OPTION-RECORD AREA, WHOSE RANGE IS
STORED SEPARATELY IN THE OPTION-RANGE WORD.

GLOBAL MODULE MODES:

'''TEXT
00  DESCRIPTOR/KINIT DEFAULT
01  LOAD REQUIRED ONLY
02  LOAD REQUIRED AND LISTED OPTIONAL MODULES
03  DISABLE OPTIONAL MODULES
04  DISABLE ALL MODULES NOT REQUIRED FOR BOOT
'''

S1CFG V1 DOES NOT STORE TEXTUAL MODULE NAMES.  IT STORES A 128-BIT STARTUP
MODULE BITMAP PLUS COMPACT OPTION RECORDS.  MODULE IDS ARE STABLE NUMERIC
VALUES:

'''TEXT
000       NONE / CTY0 BUILTIN SPECIAL CASE
001..003  RESERVED GLOBAL OWNERS
004..037  BOOT-DEVICE MODULES
040..177  OTHER STARTUP MODULES
'''

COMPACT OPTION RECORDS ARE ONE WORD EACH:

'''TEXT
BITS 35..28  OWNER ID, 0..3 GLOBAL OR 4..177 MODULE ID
BITS 27..24  OPTION KEY
BITS 23..0   OPTION VALUE
'''

THE CURRENT LOADER DOES NOT USE THIS BITMAP.  IF S1CFG IS REVIVED, STAGE1 SHOULD
STILL AVOID BECOMING A MODULE LOADER.  THE SELECTED MODULE IDS SHOULD FEED THE
IMAGE GENERATOR, INSTALLER, OR KINIT-VISIBLE CONFIGURATION.  THE ACTUAL
MINIT/MRES LIFETIME SPLIT BELONGS TO THE DMANIF STREAM AND KINIT.

THE PLANNED SELECTED SET IS:

'''TEXT
SELECTED BOOT-DEVICE MODULE
STARTUP BITMAP MODULES FROM S1CFG
DMANIF ENTRIES MARKED REQUIRED
'''

CTY0 REMAINS A BUILTIN SPECIAL CASE.

## 9. MODULE LOADING BOUNDARY

THE CURRENT BOOT PATH HAS NO STAGE1-PARSED 'MODULES' REGION.  MODULE LAYOUT
LIVES IN THE DMANIF MANIFEST AT THE FRONT OF THE INIT STREAM.  STAGE1 ONLY
LOADS THE KRES PAYLOAD AND THE OPAQUE INIT STREAM SIZES FROM THE DAIMON IMAGE
HEADER.

KINIT MUST UNDERSTAND THESE DMANIF FIELDS:

'''TEXT
MODULE_ID
MODULE FLAGS, INCLUDING REQUIRED
MINIT WORDS
MRES WORDS
'''

KINIT USES THOSE FIELDS FOR TWO PASSES:

'''TEXT
PASS 1: VALIDATE MANIFEST AND SUM SELECTED MRES/MINIT MEMORY
PASS 2: COPY MRES UPWARD AFTER KRES
        DISPATCH MINIT FROM THE RECLAIMABLE INIT STREAM
        RECORD LOADED RESIDENT MODULE STATE
'''

THIS KEEPS STAGE1 FROM BECOMING A LINKER WHILE PRESERVING THE CORRECT MEMORY
LIFETIME LAYOUT.

V1 MUST NOT LOAD MODULES AS 'MINIT,MRES,MINIT,MRES'.  THAT WOULD MAKE LATER
INIT-MEMORY RECLAIM LEAVE HOLES BETWEEN RESIDENT MODULE BODIES.

## 10. OPERATOR PROMPT POLICY

THE NORMAL STAGE1 LOADER CAN HAVE A TINY ONE-CHARACTER OVERRIDE PATH, BUT ONLY
WHEN ENABLED BY BCF OR BY A FUTURE STAGE0 HANDOFF WORD.

RECOMMENDED MINIMAL STAGE1 PROMPT COMMANDS:

'''TEXT
<CR>  BOOT DEFAULT
S     SINGLE-USER FOR THIS BOOT
V     VERBOSE FOR THIS BOOT
C     CTY-ONLY FOR THIS BOOT
?     PRINT COMPACT BOOT DEVICE SUMMARY
H     HALT
'''

FULL EDITING BELONGS TO THE BOOTCFG TAPE OR OS BOOTCFG PROGRAM.

## 12. IMPLEMENTATION ORDER

1. ADD 'BOOTCFG_CORE' HOST TESTS FOR BCF PARSING/CHECKSUM/SELECTION.
2. ADD A HOST-ONLY BCF WRITER/READER TO PROVE CFGSTORE LAYOUT.
3. EXTEND BOOTINFO WITH SELECTED BOOT FLAGS AND BOOTDEV WORD.
4. TEACH A FUTURE STAGE1 OR KINIT CONFIGURATION IMPORTER TO READ BCF FROM
   CFGSTORE AFTER DBOOT VALIDATION.
5. DEFINE HOW S1CFG POLICY MAPS ONTO THE CURRENT DBX/KICFG AND DMANIF MODULE
   SELECTION PATH.
6. HOST-TEST SELECTED-SET AND MRES/MINIT PACKING CALCULATIONS IN THE IMAGE
   GENERATOR/KINIT PATH.
7. KEEP KINIT RESPONSIBLE FOR VALIDATING, BINDING, INITIALIZING, AND RECLAIMING
   MINIT.
8. BUILD THE OS 'BOOTCFG' TOOL AROUND THE SAME CORE.
9. BUILD THE STANDALONE BOOTABLE BOOTCFG PAPER TAPE WITH ONLY DSK270 FIRST.
10. ADD DTC/DECTAPE SUPPORT TO THE STANDALONE TAPE AFTER THE DECTAPE BLOCK
    MAPPING IS FROZEN.

V1 SHOULD IMPLEMENT ONLY PDP-6 DSK270 STAGE1 SELECTION.  THE DEVICE IDS ABOVE ARE
RESERVED NOW SO THE ON-DISK FORMAT WILL NOT NEED RENAMING WHEN DECTAPE AND KA10
STORAGE DRIVERS ARRIVE.


## 18. FIRST IMPLEMENTATION PASS

THE FIRST IMPLEMENTATION PASS ADDED A SMALL C CORE FOR THE COMPACT BCF SECTOR:

'''TEXT
INCLUDE/S1CFG_V1.H    STABLE CONSTANTS, BIT PACKING, PARSER API
LIB/S1CFG_V1.C        CHECKSUM, PARSER, DEFAULT RECORD WRITER, MODULE BITMAP
                      UPDATE HELPERS
TESTS/TEST-S1CFG-V1.C HOST TEST FOR DEFAULT RECORDS, OPTION RECORDS, BITMAP
                      BOUNDARY HANDLING, AND INVALID-RECORD REJECTION
'''

THIS CODE IS NOT PART OF THE CURRENT DEFAULT HDD BOOT PATH.  CURRENT BOOTSETS
CARRY KICFG IN DBX/DBC AND MODULE LAYOUT IN DMANIF.  THE IMAGE GENERATOR REJECTS
OBSOLETE S1CFG/S1CONF FALLBACK OPTIONS RATHER THAN EMITTING A LIVE S1CFG SECTOR.

A REAL BUG CLASS WAS COVERED DURING THE FIRST HOST TEST: MODULE ID 0177 USES BIT
19 OF THE FINAL BITMAP WORD, SO ONLY BITS 20..35 OF THAT WORD ARE RESERVED.
