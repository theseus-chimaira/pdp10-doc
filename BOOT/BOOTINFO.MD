# BOOTINFO HDD V1

STATUS: CURRENT STAGE1-TO-KINIT HANDOFF.  SOURCE OF TRUTH:
'../DAIMOS/INCLUDE/BOOTINFO_HDD_V1.H' AND
'../DAIMOS/BOOT/PDP6/HDD_DBOOT_V1/BOOTINFO_V1.C'.

THE BOOTINFO RECORD IS FIXED AT 035 WORDS AND IS WRITTEN AT '073000'.
KINIT RECEIVES ITS ADDRESS IN AC1.  THE COMMON HEADER USES MAGIC 'BI2' AND
VERSION 2; THE SURROUNDING BOOT ABI IS STILL DAIMON BOOT ABI V1.

## LAYOUT

'''TEXT
000  HEADER: BI2 ! VERSION=2 ! COUNT ! FLAGS
001  TOTAL WORDS, 035
002  FLAGS
003  BOOT DEVICE
004  BLOCKSET UUID WORD 0
005  BLOCKSET UUID WORD 1
006  MEMBER ORDER HIGH WORD
007  DESCRIPTOR GENERATION
010  MEMBER SUMMARY: MASK16 ! COUNT5
011  MEMBER ORDER LOW WORD
012  STAGE1 WARNING FLAGS
013..022  DBOOT LOCATORS, TWO 18-BIT LOCATORS PER WORD
023  KRES PAYLOAD LOAD BASE, CURRENTLY 000040
024  KRES FILE WORDS
025  KRES MEMORY WORDS
026  DAIMON/KINIT ENTRY ADDRESS
027  INIT STREAM START
030  KINIT FILE WORDS ALIAS, RETAINED FOR ABI NAMING
031  INIT STREAM WORDS
032  KINIT ENTRY OFFSET
033  MODULE START ALIAS
034  MODULE WORDS ALIAS
'''

THE HIGH-MEMORY STREAM IS OPAQUE TO STAGE1.  'BOOTINFO_WORD_INIT_START' AND
'BOOTINFO_WORD_INIT_WORDS' NAME THE COMPLETE STREAM, NOT A SEPARATELY LOADED
KINIT-ONLY REGION.

## MEMBER MAPPING

SIXTEEN FOUR-BIT PHYSICAL UNIT NUMBERS ARE PACKED INTO TWO WORDS.  FIVE SPARE
BITS CARRY THE MEMBER COUNT.  THE DBOOT LOCATOR ARRAY IDENTIFIES EITHER A DBC
SECTOR DIRECTLY OR A DB0 SECTOR; KINIT READS THE MAGIC AND DERIVES DBX FROM DB0
WHEN NEEDED.

BOOTINFO DELIBERATELY HAS NO CHECKSUM AND NO COPIED BAD-RUN TABLE.  KINIT
REREADS AND VALIDATES THE DESCRIPTORS FOR SELECTED MEMBERS.

## WARNING BITS

THE WARNING WORD USES THE 'DBOOT_WARN_*' BITS FROM 'DBOOT_V1.H'.  CURRENT
IMPORTANT MEANINGS INCLUDE:

'''TEXT
000000000020  SOME BAD SECTORS WERE PRESENT
000000000040  NON-BOOT DISKS WERE PRESENT
000000000100  ANOTHER MEMBER SET WAS INCOMPLETE
000000000200  SINGLE-DISK BOOT SET
000000001000  GENERATION MISMATCH OBSERVED
000000002000  EXTRA BOOTABLE MEMBER SEEN
'''

ERRORS BEFORE THE HANDOFF ARE FATAL STAGE1 ERRORS, NOT BOOTINFO STATUS CODES.
