## STRICT VERSUS ICE-ONLY STATUS ACCOUNTING

THE NORMAL RUNNER'S **DEFAULT IS STILL STRICT**. THE
OPTIONAL `--exit-policy ice-only` CHANGES ONLY THE PROCESS
EXIT DECISION. COMPILE, LINK, GUEST RUNTIME AND TIMEOUT
FAILURES REMAIN AUTHENTIC, REPORTABLE FAILURES IN PER-CELL
CHECKPOINTS, `failures.tsv` AND `summary.txt` `fail=`.
THE SEPARATE `exit_fail=` SUMMARIZES FATAL CONDITIONS.

AN ACTUAL COMPILER ICE, TESTKIT SETUP/POLICY FAILURE,
UNKNOWN/INCOMPLETE RESULT OR MISSING SOURCE IS ALWAYS
FATAL EVEN WITH ICE-ONLY SELECTED. ALL HISTORY AND RAW
LOGS ARE RETAINED. THE ORIGINAL ICE REGULAR EXPRESSION
WAS ALSO TIGHTENED SO AN OUTPUT PATHNAME CONTAINING THE
WORD `ice-only` CANNOT FALSIFY A GCC MISSING-HEADER ERROR
AS A COMPILER ICE. REAL GCC/KCC INTERNAL ERRORS AND
COMPILER CRASHES REMAIN RECOGNIZED.

`--source-file` SELECTS A LIST OF REGISTERED SOURCE PATHS,
WITH EXPLICIT REJECTION OF DUPLICATES, MISSING SOURCES,
UNSAFE PATHS AND EMPTY LISTS. VERSIONED PATH LISTS FOR
ALL HISTORICAL P1 C SOURCES, THE NEW 38 P1 ORIGINALS,
AND THE 105 C-TO-ISA SOURCES ARE INCLUDED IN TESTKIT.
