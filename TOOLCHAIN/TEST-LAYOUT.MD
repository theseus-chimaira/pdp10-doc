# TEST LAYOUT

THE SUITE HAS ONE PERMANENT MATRIX:

- 'TEST_MATRIX.TSV'

ALL TEST SOURCES ARE BELOW 'TESTS/':

- 'TESTS/SEMANTIC/': TESTS THAT COMPILE, LINK, AND RUN IN 'P10BARE'
- 'TESTS/CODEGEN/': TESTS THAT COMPILE TO ASSEMBLY AND ARE CHECKED BY CODEGEN POLICY DIRECTIVES
- 'TESTS/ISA/': SOURCE-LEVEL INSTRUCTION COVERAGE USED BY MATRIX-SELECTED COMPILER CELLS
- 'TESTS/VALIDATION/': FOCUSED COMPILER-VALIDATION ROWS

SUPPORT FILES ARE BELOW 'SUPPORT/':

- 'SUPPORT/CRT0.S': SEMANTIC-TEST ENTRY/EXIT SUPPORT
- 'SUPPORT/INCLUDE/': SHARED C HEADERS
- 'SUPPORT/KCC/': KCC-SPECIFIC HEADERS
- 'SUPPORT/GCC/': GCC-SPECIFIC HEADERS

RUNNER TOOLS ARE INTENTIONALLY SMALL:

- 'TOOLS/RUN-TESTS.PY': THE ONLY COMPILER TEST RUNNER
- 'TOOLS/STUBSELECT.PY': SELECTS SUPPORT STUBS REFERENCED BY GENERATED ASSEMBLY
- 'TOOLS/VERIFY-TESTKIT-LAYOUT.PY': CHECKS THAT THE COMMITTED LAYOUT REMAINS SIMPLE

GENERATED OUTPUT IS BELOW 'WORKDIR/' AND IS DISPOSABLE.
