# KCC PDP-10 STDARG VA_END ARGUMENT EVALUATION (2026-11-20, V1)

## VERIFIED BEHAVIOR

KCC'S PDP-10 TARGET ABI DOES NOT NEED A RUNTIME FINALIZATION
OPERATION FOR `va_list`.  HOWEVER, THE `va_end(ap)` MACRO MUST
EVALUATE ITS ARGUMENT EXPRESSION EXACTLY ONCE, INCLUDING SIDE
EFFECTS SUCH AS THE POINTER POST-INCREMENT IN
`va_end(**ap_ptr++)`.

THE PREVIOUS `kcc/self/include/stdarg.h` DEFINITION

```c
#define va_end(ap) ((void)0)
```

DISCARDED THE ARGUMENT AND LOST THE SIDE EFFECT.  THE CORRECTED
DEFINITION IS

```c
#define va_end(ap) ((void)(ap))
```

THIS RETAINS THE EXISTING ZERO-CLEANUP ABI, ADDS NO NEW RUNTIME
DEPENDENCY, AND DOES NOT CHANGE THE GCC DELEGATION THROUGH
`#include_next <stdarg.h>`.

THE FIX IS COMMITTED IN THE OWNING `kcc` REPOSITORY AS `5fa3510`
AND WAS INSTALLED USING THE COMPILER'S `install-headers` TARGET
INTO `$PDP10_PREFIX/lib/kcc/include/stdarg.h`.  THE INSTALLED
HEADER IS BYTE-IDENTICAL TO THE SOURCE, SHA256
`f966aa2588b7d59dbf2bf704ffd87fb67097673455ee77fe86d8a75232f23e7f`.
THE COMPILER EXECUTABLE, LINKER, ASSEMBLER, EMULATOR AND TARGET
C LIBRARY WERE NOT MODIFIED.
