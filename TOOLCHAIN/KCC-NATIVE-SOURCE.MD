# NATIVE KCC SOURCE PACKAGE

THE DAIMOS PDP-6 BOOT-IMAGE BUILD INSTALLS THE CURRENT KCC COMPILER SOURCE
TREE UNDER /OPTION/SOURCE/KCC. THE DIRECTORY INCLUDES THE ROOT C AND HEADER
FILES, THE ROOT ASSEMBLER SOURCE, RUNTIME C/ASSEMBLER SOURCES, AND THE SELF
INCLUDE HEADERS. IT ALSO CONTAINS A NATIVE MAKEFILE.

THE SOURCE DIRECTORY IS DISTINCT FROM THE EXECUTABLE INSTALLATION AT
/OPTION/BASE/EXEC/KCC AND /OPTION/BASE/LIBEXEC/KCC.

## FORMATS

C AND HEADER FILES USE C-SIX ENCODING, WHICH PRESERVES THE CASE-SENSITIVE C
TOKEN REPERTOIRE ON SIXBIT RECORD FILES. HISTORICAL FORM-FEED PAGE SEPARATORS
ARE REPLACED WITH SPACES, AND TABS ARE EXPANDED TO SPACES. ASSEMBLER SOURCES
ARE PACKED AS UPPERCASE S6REC FOR NATIVE DAS. THE MAKEFILE IS UPPERCASE
S6REC AND USES THE NATIVE '>' RECIPE MARKER.

## NATIVE COMMANDS

FROM DSH, THE USER CAN RUN:

    MAKE -C /OPTION/SOURCE/KCC HELP
    MAKE -C /OPTION/SOURCE/KCC CCVLA.S
    MAKE -C /OPTION/SOURCE/KCC CCVLA.DOBJ

THE LAST TWO COMMANDS EXERCISE THE GENERIC .C.S AND .S.DOBJ TRANSFORMATIONS.
THEY ARE EXAMPLES FOR MANUAL ACCEPTANCE, NOT CLAIMS THAT CCVLA HAS ALREADY
COMPILED SUCCESSFULLY ON THE TARGET.

THE NATIVE MAKEFILE DOES NOT YET IMPLEMENT A COMPLETE REBUILD OF KCPP,
KPARSE, KGEN, KOPT, AND THE KCC DRIVER. THAT REQUIRES NATIVE COMPILER PROFILE
OPTIONS, PHASE-SPECIFIC OBJECT CLOSURES, AND A COMPLETE LIBRARY/LINK SET.
DO NOT USE 'MAKE' SUCCESS ON THE HELP TARGET AS A SELF-HOSTING ACCEPTANCE.

## HOST PACKAGING VALIDATION

THE HOST BOOT-IMAGE BUILD CONVERTS ALL SELECTED SOURCES AND ADDS THEM TO
D6FS. THE FOUR-MEMBER IMAGE HAS BEEN CHECKED WITH D6FSCK. THIS CHECK DOES
NOT EXECUTE KCC, MAKE, DAS, OR DLINK UNDER THE PDP-6 SIMULATOR.
