# NATIVE KCC SOURCE PACKAGE

THE DAIMOS PDP-6 BOOT-IMAGE BUILD INSTALLS THE CURRENT KCC COMPILER SOURCE
TREE UNDER /OPTION/SOURCE/KCC. THE DIRECTORY INCLUDES THE ROOT C AND HEADER
FILES, THE ROOT ASSEMBLER SOURCE, RUNTIME C/ASSEMBLER SOURCES, SELF INCLUDE
HEADERS, DAIMOS ABI HEADERS, AND BOOTSTRAP OBJECTS/ARCHIVE. THE TWO NATIVE
BUILD FILES ARE MAKEFILE AND DAIMOS.MK.

THE SOURCE DIRECTORY IS DISTINCT FROM THE EXECUTABLE INSTALLATION AT
/OPTION/BASE/EXEC/KCC AND /OPTION/BASE/LIBEXEC/KCC.

## FORMATS

C AND HEADER FILES USE C-SIX ENCODING, WHICH PRESERVES THE CASE-SENSITIVE C
TOKEN REPERTOIRE ON SIXBIT RECORD FILES. HISTORICAL FORM-FEED PAGE SEPARATORS
ARE REPLACED WITH SPACES. ASSEMBLER SOURCES ARE UPPERCASED, TABS EXPANDED,
AND PACKED AS S6REC FOR NATIVE DAS. MAKEFILE IS UPPERCASE S6REC WITH A
DAIMOS PLATFORM SELECTOR. DAIMOS.MK IS UPPERCASE S6REC WITH NATIVE '>'
RECIPE MARKERS.

## NATIVE COMMANDS

FROM DSH, THE USER CAN RUN:

    MAKE -C /OPTION/SOURCE/KCC NATIVE
    MAKE -C /OPTION/SOURCE/KCC BUILD/KCPP.DXR

THE CURRENT DAIMOS.MK DECLARES SOURCE, OBJECT, ARCHIVE, AND LINK RULES FOR
KCPP, KPARSE, KGEN, KOPT, AND THE KCC DRIVER. IT USES INSTALLED BOOT OBJECTS
AND THE NATIVE LIBC ARCHIVE. THESE ARE INTENDED NATIVE BUILD COMMANDS, NOT
PROOF THAT ALL PHASES COMPILE, LINK, OR PASS SELF-HOSTING TESTS ON TARGET.

## HOST PACKAGING VALIDATION

THE HOST BOOT-IMAGE BUILD CONVERTS SELECTED SOURCES AND INSTALLS THEM IN
D6FS UNDER /OPTION/SOURCE/KCC. D6FS IMAGE VALIDATION IS NOT EQUIVALENT TO
EXECUTING KCC, MAKE, DAS, OR DLINK INSIDE THE PDP-6 SIMULATOR. NO NEW
NATIVE ACCEPTANCE RESULT IS CLAIMED IN THIS DOCUMENT UPDATE.
