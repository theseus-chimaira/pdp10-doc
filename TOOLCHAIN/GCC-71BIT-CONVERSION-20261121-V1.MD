# PDP-10 GCC 71-BIT FLOATING CONVERSION ABI (2026-11-21, V1)

## IMPLEMENTATION AND ABI

GCC COMMIT `bca60ef` COMPLETES THE SIX NATIVE PDP-6 KCC/GCC
COMPILER PROFILES FOR THE UNCHANGED HISTORICAL P1 `conversion.c`.
THE ORIGINAL C SOURCE HAS SHA256
`2736912e40e1dabd84f7f193ddaaf5ddf9bf00e76edb0cca0611b3f49e5c1beb`.
ITS FULL GNU-ONLY 71-BIT SIGNED/UNSIGNED `long long` ASSERTIONS
NOW EXECUTE TO A REAL SIMH HALT WITH EXIT ZERO. NO ASSERTION,
HOSTED-LIBC SUBSTITUTE OR ORIGINAL SOURCE WAS MODIFIED.

THE GCC PDP-10 DImode ABI CONSISTS OF A 36-BIT HIGH INTEGER WORD
IN AC1 AND A 35-BIT LOW PAYLOAD IN AC2. AC2'S HIGHEST BIT IS THE
COPY OF AC1'S SIGN. FLOATING INPUTS/RESULTS ARE SF IN AC1 OR
D-FORMAT IN AC1:AC2, WITH 27+35 FRACTION BITS.

THE OWNING GCC `gcc/config/pdp10/libgcc1.s` NOW CONTAINS THESE
SIX INDEPENDENT LIBRARY MEMBERS, REGISTERED UNDER
`gcc/config/pdp10/t-none`:

* `__fixunssfdi` - SINGLE PRECISION TO UNSIGNED 71-BIT INTEGER;
* `__fixsfdi` - SINGLE PRECISION TO SIGNED 71-BIT INTEGER;
* `__fixunsdfdi` - D-FORMAT TO UNSIGNED 71-BIT INTEGER;
* `__fixdfdi` - D-FORMAT TO SIGNED 71-BIT INTEGER;
* `__floatdidf` - SIGNED 71-BIT INTEGER TO FULL D-FORMAT;
* `__floatdisf` - SIGNED 71-BIT INTEGER DIRECTLY TO SF.

THE INTEGER-TO-SF HELPER RETAINS ALL 71 BITS UNTIL THE FINAL
27-BIT MANTISSA IS ROUNDED NEAREST/TIES-TO-EVEN. IT EXAMINES
THE FULL GUARD/STICKY INFORMATION AND AVOIDS DOUBLE ROUNDING
THROUGH D-FORMAT. THE SIGNED/UNSIGNED REVERSE CONVERTERS USE
FULL-WIDTH INTEGER ALIGNMENT AND TWO-WORD SIGN CARRY; NEGATIVE
FRACTIONS TRUNCATING TO ZERO RETURN TWO CANONICAL ZERO WORDS.
IN PARTICULAR, THE OLD GCC GENERIC D-FORMAT FIX OPERATIONS
COULD ENTER VERY LONG-RUNNING FLOATING-SUBTRACTION/DIVISION
SEQUENCES UNDER PDP-6 SIMH. THE CURRENT TARGET-OWNED HELPERS
DO NOT REQUIRE THOSE OPERATIONS OR HOSTED/DAIMOS LIBC.

THE COMPILER RUNTIME USES BOUNDED SCRATCH-REGISTER STACK SAVES,
NO HEAP, NO WRITABLE STATIC STATE, AND ONLY PDP-6 BASELINE
INSTRUCTIONS. UNTOUCHED LIBGCC ARCHIVE MEMBERS ARE PRESERVED.

`67ebf49eb2d7eb896b7f95e0aab9bab3f94c148ce914297f4ff1cf1c61cedfc7`.
