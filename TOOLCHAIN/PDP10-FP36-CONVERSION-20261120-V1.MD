# PDP-10 NATIVE 36-BIT FLOATING CONVERSION CORRECTION (2026-11-20, V1)

## VERIFIED SCOPE

PDP-6 REAL-EXECUTION TESTS HAVE VERIFIED THE 36-BIT SIGNED AND
UNSIGNED INTEGER / SINGLE- AND DOUBLE-FORMAT CONVERSION REPAIR
IN BOTH KCC AND GCC COMPILERS.  THESE ARE TARGET COMPILER AND
RUNTIME REPAIRS, NOT ALTERATIONS TO HISTORICAL TEST ASSERTIONS.
THE FULL ORIGINAL `conversion.c` IS **NOT YET COMPLETE**.

THE OLD COMPILER OUTPUT USED `FSC` TO SET AN EXPONENT ON AN
UNNORMALIZED INTEGER.  THIS DID NOT PLACE THE SIGNIFICAND AT
ITS CANONICAL PDP-10 FLOATING POSITION.  THE OLD UPPER-RANGE
UNSIGNED PATH DISCARDED NINE SIGNIFICANT LOW BITS; THE OLD
SIGNED `FIX` COULD RETURN ZERO FOR THE VALID `-2^35` MINIMUM.
THE OLD GCC SI-TO-D-FORMAT LOWERING ROUTED THROUGH SINGLE
PRECISION, LOSING BITS THAT ARE EXACTLY REPRESENTABLE IN THE
62-BIT D-FORMAT FRACTION.

### GCC OWNERSHIP

GCC COMMIT `4e9f943` REPAIRS NORMALIZATION, NEAREST/TIES-TO-
EVEN, FRACTION CARRY, AND SIGNED-MINIMUM CONVERSION.  IT
ADDS REAL `__fixunssfsi` AND `__floatunsidf` LIBGCC1 MEMBERS,
AND CHANGES PDP-6 UNSIGNED SI-TO-DF CODE GENERATION TO USE
THE EXACT D-FORMAT HELPER RATHER THAN SINGLE PRECISION.
THE GENERIC LIBGCC2 DUPLICATES ARE EXCLUDED FROM TARGET
ARCHIVE ASSEMBLY.
