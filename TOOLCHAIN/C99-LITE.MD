# KCC DAIMON C99-LITE FUTURE WORK

DATE: 2026-06-20

THIS DOCUMENT IS THE FORWARD PLAN FOR ADDING USEFUL MODERN C FEATURES TO KCC
WITHOUT MAKING NATIVE PDP-6/KA10 SELF-HOSTING IMPRACTICAL.

THE UPLOADED KCC TREE ALREADY CONTAINS THE FOLLOWING MODERN-FEATURE WORK, SO IT
IS NOT LISTED AS IMPLEMENTATION WORK HERE:

- 71-BIT 'LONG LONG' AND 'UNSIGNED LONG LONG' FRONT-END, CONSTANT, COMPARE,
  ARITHMETIC, MOVE/STORE/RETURN, AND SEVERAL CODE GENERATION PATHS.
- '//' LINE COMMENTS.
- 'INLINE', '__INLINE', '__INLINE__' ACCEPTED.
- 'RESTRICT', '__RESTRICT', '__RESTRICT__' ACCEPTED.
- '_BOOL' ACCEPTED AS AN INT-BACKED SCALAR.
- '_STATIC_ASSERT' AND 'STATIC_ASSERT' ACCEPTED.
- '__FUNC__', '__FUNCTION__', AND '__PRETTY_FUNCTION__' ACCEPTED.
- 'TYPEOF', '__TYPEOF', AND '__TYPEOF__' ACCEPTED.
- BINARY INTEGER LITERALS, FOR EXAMPLE '0B1010'.
- INTEGER DIGIT SEPARATORS, FOR EXAMPLE '1'000' AND '0B1010'0101'.
- '#WARNING'.
- '#PRAGMA ONCE' / '#PRAGMA INCLUDE_ONCE'.
- '__COUNTER__'.
- '__ATTRIBUTE__((...))', '__ATTRIBUTE', AND C++ STYLE '[[...]]' ATTRIBUTES
  ACCEPTED AND IGNORED.
- MIXED DECLARATIONS AFTER STATEMENTS.
- 'FOR (INT I = ...; ...; ...)' SYNTAX ACCEPTED.
- GNU COMPUTED GOTO SYNTAX: '&&LABEL' AND 'GOTO *EXPR'.

SOME OF THE ACCEPTED FEATURES STILL NEED SEMANTIC HARDENING, SCOPING FIXES,
HEADERS, DOCUMENTATION, OR PDP-6/KA10 MATRIX TESTS. THOSE ARE LISTED BELOW.

## HARD RESOURCE RULE

THE NATIVE SELF-BUILD TARGET REMAINS A 256KW PDP-6/KA10-CLASS SYSTEM.

A FEATURE IS ACCEPTABLE ONLY IF KCC STILL SELF-BUILDS WITHIN THAT BUDGET WITH
ROOM LEFT FOR STACK, RUNTIME, FILESYSTEM BUFFERS, AND DIAGNOSTICS.

INITIAL BUDGET TARGET:

'''TEXT
PREFERRED NORMAL COMPILE FOOTPRINT: <= 200KW
HARD LARGE-FILE COMPILE CEILING:     <= 230KW
REQUIRED EMERGENCY/SLOP SPACE:       >= 26KW
COMPILER TEXT TARGET:                <= 80KW
COMPILER STATIC DATA+BSS TARGET:     <= 24KW
HEAP+STACK+RUNTIME TARGET:           <= 120KW
'''

DO NOT ADD UNBOUNDED TOKEN BUFFERING, FULL-SOURCE LOADING, FULL AST RETENTION,
UNBOUNDED MACRO RECURSION, OR HEAP-HEAVY TOKEN OBJECTS.
